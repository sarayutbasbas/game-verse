# Game box gallery

The catalogue presents all twelve games as equally sized, freestanding illustrated boxes. Generated English titles are printed on the front and left spine; a visible native title below each box and descriptive link identify every game. The original cover remains available elsewhere and supplies the masked artwork behind each box.

The shelf uses warm pale oak `#d8c19e`, translucent white `#ffffffc7`, ink `#243341`, muted slate `#60717e` and forest teal `#285e56`. Existing Noto Sans Thai carries interface copy; game titles use Georgia/Times with Thai fallback. Generated lettering follows each game's theme. Recent games have four small columns in one row; the complete catalogue has two columns on desktop, tablet and phone. Every transparent box PNG is640×800, with a576×728 box at the same position. Captions pull into the transparent lower margin so names stay visually attached to their boxes. Player counts appear in cream oval badges over the top-right corner. Hover/keyboard focus lifts the box and reveals the artwork behind it; reduced-motion mode keeps it still. No automatic animation.

“เกมล่าสุด” precedes “เกมทั้งหมด” when matching recent games exist. The recent section shows up to four unique known games from authenticated server history, newest first. A native details-based quick filter always sits beside the “เกมทั้งหมด” heading and filters both sections using supported player counts. Its maximum comes from catalogue metadata; selection persists in the URL and clears with “ทุกจำนวน”. Selection closes the menu and returns keyboard focus; Escape/outside-content clicks also dismiss. There is no search form, save control or active-room list on home. Existing room links appear on the corresponding game's entry page, using authenticated active memberships and the correct player/display route. The standalone join page remains available and can list authenticated rooms across games; local Name It starts fresh and keeps the current match only in page memory.

The platform header has a generated transparent GameVerse masthead and remains sticky at the viewport top. Profile controls remain native and interactive; sound controls appear during play and are omitted in QR lobbies. A generated tabletop background sits behind a translucent white content sheet; game play surfaces retain their own themes. Assets and exact built-in imagegen prompts are recorded in `platform-theme-art-jobs.json`; runtime assets live in `public/art/platform/` (800×168 PNG masthead and optimized WebP background, about390KB combined).

The complete catalogue displays ten games per page, with centered44px circular page buttons and a forest-green current-page state (`aria-current="page"`). Recent games remain a separate four-item row. Page selection persists in the URL, out-of-range pages clamp to the last available page, and changing the player filter resets to page1. Changing pages focuses the catalogue heading below the sticky header. Pagination disappears for ten or fewer matching games.

The profile page uses a cream player-card frame, forest-green top edge, gold-ringed96px avatar token and account-type badge. Native photo selection, independent name drafts, inline save/reset/status controls, Google linking and logout retain their existing behavior. Account help is folded into a details section; Guest/member and optional admin controls remain distinct. The shared tabletop background/masthead continue around the card.

The original generated PNGs remain in the generator's output directory. Runtime files are under `public/art/boxes/`. `game-box-art-jobs.json` records the built-in imagegen prompts and source paths. `node scripts/prepare-game-boxes.mjs` normalizes those sources and compresses transparent PNGs; it requires the recorded local source files. Combined runtime PNG size is approximately2.9MB. Current-page faces decode before an atomic list update; the first two receive high fetch priority.

Guest avatars use a centered inline grid and a symmetric24-unit silhouette with equal top/bottom margins. The lobby's generic span rule no longer overrides its layout.

Game entry pages use the same PNG box and serif title. Critter Kitchen/Locus keep their existing native mobile-mode dropdown beside a green circular GO control; other games retain their supported creation flow. The accessible control name remains “สร้างห้องบนจอกลาง”. Eligibility/offline/pending states still disable creation, with login guidance for Guests. Join cards group room code and name side by side on wider screens and vertically on phones. QR links show the fixed room code and only request a name. Native form submission, pasted-code normalization, readonly member names and inline errors remain. The bottom game-selection link was removed; the header brand leads home.

`platform-gallery.ts` retains the gallery section and card/image nodes across filters, pages and shared-room detail navigation. Header/connection updates preserve platform chrome; same-origin portal links/history between the catalogue and supported room-game details reuse the document, URL filters and gallery scroll. Local Name It and authenticated room routes retain their existing navigation/session lifecycle. Catalogues swap decoded cached nodes together rather than rebuilding image trees. Mobile background art is aligned left, behind a more transparent white sheet.

QR lobbies use box art, centered invitation/QR and the same dimensional GO size as entry pages. Lobby sound controls are omitted; in-game sound remains. Critter Kitchen option headings keep their checkboxes and details foldouts; expanded sections and selected options survive lobby updates. Existing rooms appear below the join form.
