# ปันผลมรณะ (Dividend Hunter)

เกมสร้างใหม่ตามแนวคิดผู้ใช้ ไม่อิงเกมกล่องที่มีจำหน่าย

- 2–120 คน จอกลางแยกจากผู้เล่น เจ้าของห้องเล่นผ่านมือถือและควบคุมห้องได้
- ตั้งก่อนเริ่ม: 1–50 รอบ (เริ่มต้น 5), เลขสูงสุด 2–10,000 (เริ่มต้น 120), เลขต่ำสุดคงที่ 1
- ทุกคนเลือกเลขจำนวนเต็มพร้อมกันและส่งครั้งเดียวในแต่ละรอบ เลขที่ส่งแล้วแก้ไม่ได้
- ยอมรับเลขตรงกัน เพื่อใช้ตัดสินว่าใครได้ 0; ไม่บล็อกเลขซ้ำขณะส่ง เพราะจะเปิดเผยตัวเลือกคนอื่น
- จอกลางแสดงเพียงจำนวนคนส่ง มือถือเห็นเลขที่ตนส่งเท่านั้นจนทุกคนส่งครบ
- เลขที่มีผู้เลือกมากกว่าหนึ่งคน: ทุกคนที่เลือกเลขนั้นได้ 0 คะแนน
- เลขที่มีผู้เลือกเพียงคนเดียว: ได้แต้มเท่าตัวเลข
- เมื่อครบคำตอบ เปิดเลข/ผลปันผลรายคนพร้อมกัน เจ้าของห้องกดรอบถัดไปได้ทั้งจากมือถือและจอกลางที่มีสิทธิ์
- จบเกมคะแนนสะสมสูงสุดเป็นผู้ชนะ; หากเสมอทุกคนที่คะแนนสูงสุดชนะร่วมกัน
- หลุดแล้วกลับเข้าด้วย session เดิม คืนเลขที่ส่งและสถานะเกมจากเซิร์ฟเวอร์ เกมคงอยู่ใน durable room store เดิม

## เปิดผลด้วยปุ่มจบรอบ

เมื่อทุกคนส่งคำตอบหรือเลขครบ เกมยังไม่แจกคะแนนหรือเปิดผล ปุ่ม “จบรอบ” จะแสดงให้ผู้เล่นทุกคนกดได้ และจอกลางของเจ้าของห้องก็กดได้ ผู้มีสิทธิ์คนใดคนหนึ่งกดครั้งเดียวจึงเปิดผลรอบนั้นพร้อมกัน รวมถึงรอบสุดท้าย การกดก่อนครบหรือกดซ้ำไม่แจกคะแนนเพิ่ม หลังเฉลยให้เจ้าของห้องเริ่มรอบถัดไปตามเดิม
