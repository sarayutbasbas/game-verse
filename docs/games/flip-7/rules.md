## สำรับและคะแนน

- ไพ่ตัวเลข79ใบ:0หนึ่งใบ,1หนึ่งใบ,2สองใบ,…,12สิบสองใบ
- ตัวปรับคะแนน6ใบ: +2,+4,+6,+8,+10 และ×2 อย่างละหนึ่งใบ
- แอ็กชัน9ใบ: Freeze,Flip Three,Second Chance อย่างละสามใบ

แต้มรอบ = ผลรวมไพ่ตัวเลข × (2ถ้ามี×2 ไม่งั้น1) + โบนัสบวก + 15เฉพาะคนเปิดเจ็ดเลขต่างกัน ผู้บัสต์ได้0รวมทั้งโบนัสทั้งหมด คะแนนสะสมเก่ายังอยู่ ไพ่ศูนย์ไม่มีแต้มแต่ช่วยนับจำนวนเลข แอ็กชัน/ตัวปรับคะแนนไม่ทำให้บัสต์และไม่นับเจ็ดเลข

## ตาเล่นและการแจก

ห้องรอเลือกเจ้ามือรอบแรกหรือสุ่มที่server เจ้ามือหมุนไปทางซ้ายทุกรอบ ในเว็บเริ่มแจก/ถามจากที่นั่งถัดจากเจ้ามือ ไปตามลำดับเข้าห้องและรวมเจ้ามือด้วย เซิร์ฟเวอร์ทำหน้าที่แจกจริง คนเป็นเจ้ามือยังเล่นบนมือถือของตนได้

เริ่มรอบแจกใบหงายหนึ่งใบให้แต่ละคน แต่หยุดแก้ผลแอ็กชันก่อนแจกต่อ ผู้รับFlip Threeก่อนถึงคิวแจกอาจมีสามใบแล้วได้ใบเริ่มของตนอีกใบ ผู้ถูกFreeze/บัสต์ก่อนถึงคิวไม่รับใบใหม่อีก เมื่อแจกครบ คนที่ยังอยู่เลือกHit(เปิดเพิ่มหนึ่งใบ) หรือStay(เก็บแต้มและออกจากรอบ) ตามลำดับ ต้องมีไพ่ในแถวอย่างน้อยหนึ่งใบจึงStayได้ ไพ่Modifierอย่างเดียวก็อยู่หยุดได้

เลขซ้ำทำให้บัสต์ทันที ไพ่ที่อยู่หน้าแต่ละคนรวมทั้งคนบัสต์ยังไม่รวมกองทิ้งจนจบรอบ การใช้Second Chanceจะทิ้งเฉพาะใบนั้นกับเลขซ้ำออกจากแถวทันที แล้วคนเล่นยังอยู่ในรอบ ถ้าเป็นHitปกติให้ถามผู้เล่นถัดไป ไม่ได้เปิดเพิ่มในตานั้น ส่วนFlip Threeยังทำครบสามใบเว้นแต่บัสต์หรือครบเจ็ดเลข

## แอ็กชัน

- **Freeze:** ผู้ที่เปิดเลือกคนที่ยังอยู่ในรอบรวมตัวเองได้ เป้าหมายเก็บแต้มและออกจากรอบ แม้เป้าหมายยังไม่ได้ไพ่ใบแรกก็ตาม เหลือคนเดียวต้องรับเอง
- **Flip Three:** ผู้ที่เปิดเลือกเป้าหมายที่ยังอยู่รวมตัวเอง เป้าหมายเปิดเพิ่มสามใบทีละใบ ทุกชนิดนับเป็นหนึ่งในสาม ถ้าบัสต์/ครบเจ็ดเลขหยุดทันที Second Chanceใบแรกที่ได้ใช้ป้องกันเลขซ้ำใบถัดไปในชุดเดียวกันได้
- **แอ็กชันซ้อนในFlip Three:** Freeze/Flip Threeเก็บไว้แก้ผลหลังชุดสามใบจบ ถ้าผู้เปิดบัสต์ให้ทิ้งไพ่แอ็กชันที่รออยู่ ไม่ส่งต่อ ถ้าเจ็ดเลขให้จบรอบทุกคนและทิ้งงานที่ค้างอยู่ ถ้ารอดคนที่เปิดชุดนั้นเป็นผู้เลือกเป้าหมายของใบที่รอ ไม่ใช่ผู้เริ่มแอ็กชันแรก หลังแก้ทั้งหมดแล้วกลับไปคนถัดจากผู้เปิดแอ็กชันแรกตามFAQ
- **Second Chance:** ใบแรกเก็บที่ตัวเอง มีได้คนละใบ ถ้าได้อีกใบต้องส่งใบใหม่ให้คนที่ยังอยู่และยังไม่มีSecond Chance ส่งไม่ได้ทิ้งใบใหม่ การส่งใบซ้ำเกิดทันทีแม้อยู่ระหว่างFlip Three แล้วจึงเปิดที่เหลือต่อ ไม่ป้องกันFreeze

หากมีแอ็กชันรอหลายใบ เว็บใช้ลำดับที่เปิดพบก่อนเป็นข้อวินิจฉัยที่ประกาศไว้ (FAQระบุให้รอชุดสามใบแต่ไม่ได้กำหนดการสลับลำดับหลายใบอย่างละเอียด) ผู้เปิดใบที่รอเป็นคนเลือกเป้าหมาย แม้ถูกFreezeจากผลก่อนหน้า ตราบใดยังมีเป้าหมายที่ถูกต้อง ถ้าไม่มีผู้เล่นเหลือจบรอบโดยไม่ขอเป้าหมายเพิ่ม

## จบรอบ / จบเกม

เจ็ดเลขต่างกันจบรอบทันที คนที่ไม่บัสต์ทุกคนได้แต้มที่ถืออยู่ อีกทางหนึ่งจบเมื่อไม่มีคนยังเล่นแล้ว รวมคะแนนครั้งเดียว ไพ่เก่ารวมกองทิ้ง ไพ่ที่ยังไม่จั่วคงลำดับเดิม ไม่สับทุกต้นรอบ เมื่อกองจั่วหมดให้สับกองทิ้งเท่านั้น ไพ่ที่อยู่หน้าแต่ละคน (รวมของคนบัสต์) และแอ็กชันที่ยังแก้ไม่เสร็จไม่ถูกนำกลับไปสับ

หลังรวมคะแนน ถ้ามีผู้เล่นแตะ200และมีผู้สูงสุดคนเดียวจบเกม ถ้าคะแนนสูงสุดเสมอกันและอย่างน้อย200 **ทุกคน** เล่นเพิ่ม ไม่ใช่เฉพาะคนเสมอ คะแนนเดิมยกไปแล้วตัดสินใหม่หลังรอบถัดไป

## Shared display / mobile / persistence

ทุกใบที่แจกเป็นข้อมูลสาธารณะ จอกลางดูทุกแถวและคะแนน มือถือมีปุ่มเฉพาะเจ้าของตาหรือผู้มีสิทธิ์เลือกเป้าหมาย แถวตัวเองอยู่ก่อน ส่วนแถวคนอื่นเปิดดูได้ ไพ่คนบัสต์ใช้หลังไพ่ช่วยระบุสถานะ แต่แตะอ่านชนิดที่เคยเปิดได้ ไม่อ้างว่าเป็นไพ่ลับใหม่ หน้าสรุปแสดงฐาน×ตัวคูณ+โบนัสแยกกัน คู่มือและคลัง22แบบอ่านได้ก่อนสร้างห้อง/จากในเกม

Server-authenticated actor,strict payload,match/round/sequence epoch,exact revision และreceipt dedupe ใช้ระบบห้องเดิม ไม่รับคะแนน ไพ่ที่ต้องการ หรือผลสุ่มจากclient. Pure engine/RNGแยกจากการวาดภาพและstorage. Public projectionไม่มีdeck order,physical instance IDs,session tokens หรือข้อมูลอนาคต Privateเพิ่มเฉพาะid/รายการคำสั่งที่คนนี้ทำได้ Hostดูไพ่เหมือนทุกคนแต่ห้ามHit/Stay/เลือกเป้าหมายแทนผู้เล่น Owner displayเริ่มรอบถัดไปและเริ่มใหม่ได้

Pipelineเก็บผู้เลือกเป้าหมาย ชุดสามใบที่ยังเหลือ งานที่รอและจุดกลับตาไว้ใน durable room storage. Reconnectยืนยันsessionเดิม ไม่สร้างผู้เล่นซ้ำ ผลสุ่มที่เปิดแล้วไม่สุ่มใหม่ Restore schema1ตรวจ94ใบครบไม่ซ้ำ,แถว/สถานะ,ไพ่รอ/queue/forced block,score ledgerตามลำดับรอบ และเงื่อนไขผู้ชนะ/เสมอ ไม่มีบริการหรือdependencyใหม่
