# Harmonies — Libellud base 2024, boards A/B and optional modules, 1–4 players

Scope: all32 base Animal cards and common board sides A/B. Optional Solo, Nature’s Spirits, and Crescendo’s Whispers module are now implemented; see [expansions.md](expansions.md) for rules, sources, privacy and the still-unimplemented Sanctuary/C/D modules. Pulse is excluded. TypeScript/DOM project, native CSS3D geometry and HTML actions with flat fallback; no extra renderer dependency. All player boards/cards and current turn's terrain are public. Bag/card-deck order stays server-only.

Components:120terrain tokens (23water,23rock,21wood,19leaf,19field,15building),32animal cards. Each of4identical-shape boards has23flat-top hex cells (five offset columns of5/4/5/4/5). Board side affects water scoring, not placement. All players agree the same side. First player last saw a magnificent landscape; web lets host select or request server randomization.

Setup all counts2/3/4: shuffle all120terrain, fill5groups of3; shuffle32animal cards, reveal5. Empty player boards, no starting cards. Cube identities are reserved per printed card space, with substitutes if physical reserve would run out. The virtual reserve tracks all remaining printed card spaces, not an invented fixed66-cube gameplay limit.

One turn: exactly once take one complete3-token group and place all3on the board, one at a time. Optional actions may occur before, between or after these placements: take at most1visibleanimal card; settle any number of animal cubes. Refill only at end of turn: selected token group from bag, animal row back to5if draw pile permits. No mandatory card acquisition. Up to4incomplete animals; completed cards move aside but retain points/cubes. No mid-turn market replacement. The server retains hand/picked/cardTaken flags across recovery.

Every terrain can go on an empty hex. No inserting below existing tokens. Rock only on rock, max3. Wood on one wood, max2; leaf can cap0/1/2wood for a tree of height1/2/3. A building is a red token on exactly one red, wood or rock token (height2); a red ground token is legal but not a scoring building/habitat building yet. Field/water never stack. A cell with an animal cube cannot receive more terrain. Optional cube placement requires the card's precise visible terrain and tree/mountain heights. Building base can be red/wood/rock. Sixrotations; no mirroring. Exactly one cube per cell. Patterns may share any supporting terrain, including terrain with another cube, but the new cube's own cell must be free. Once placed, a cube/earned progress remains even if other supporting cells later change. Explicit server matching returns each valid origin/rotation/cube destination, never auto-selects a strategic match.

Scoring: trees1/2/3high score1/3/7; bare wood0. Mountains1/2/3high score1/3/7only if adjacent to another visible mountain. Field connected components with at least2yellow cells score5each, regardless of size. A height2building scores5if its neighboring top tokens include at least3distinct colors (empty cells excluded; red counts). A-side river is the maximum, over pairs of connected blue endpoints, of their shortest path length including endpoints. Branches and loops do not count all blue cells by default. Length1/2/3/4/5/6 =0/2/5/8/11/15, then+4peradditional cell. B-side islands are connected non-blue hex groups, including empty land and all other terrain, each5points. Normally there is at leastone island; the implementation counts actual non-blue components.

Animal points are the card's score at the latest uncovered cube space (ascending progression in catalog). No cube removed means0, incomplete cards still score achieved progress. Cubes come from bottommost printed space in order; generated diagrams and score tracks are code, independent from illustration. Full card list with scores, exact ordered stacks, axial offsets and cube cells lives in `src/games/harmonies/catalog.json` (all32records).

At end of a turn, trigger final round if active board has2or fewer empty hexes or bag cannot refill the group. Finish the round from initial starter so everyone takes the same number of turns. With120tokens and groups of3, bag refill always uses complete groups until none remain; unused public groups can supply remaining final-round players. Scores stay on finished boards until authorized restart. Highest total wins, then most placed animal cubes, then shared victory. No auto-reset or timer-dependent game rules.

Web rematch preference (2026-10-15): initial lobby setup chooses the common A/B side explicitly; clicking “เริ่มเล่นใหม่” requests a fresh server-side 50/50 A/B sample. Repeated sides are allowed. This automates the group's side choice, not a new official rule or a player-count restriction. Official setup (current English rulebook, p.2) has players collectively choose the same side and recommends A for the first few games.
