## Harmonies scroll-jank diagnosis - 17 October 2026
Read-only product investigation after the user isolated the symptom to vertical scrolling. Reproduced the dense room in an isolated temporary server, Chromium390x620 at DPR3. A temporary800px spacer supplied a repeatable scroll range because the fixture itself fit the viewport. Compared seven CSS variants at1x and4x CPU throttling; every variant used six synthesized300px touch-scroll gestures. Product source and the Docker room/data were not changed.

Observed3159 garden DOM nodes,2347 visible nodes,960 board cylinder-wall elements plus688 card-example wall elements (1168 visible). Baseline compositor tree had1504 drawing layers. At1x baseline rAF interval median49.9ms/p9583.3ms, repeated baseline49.9/66.7ms. Hiding only board walls produced16.8/50ms and1024 drawing layers. Hiding card habitat scenes produced16.7/33.4ms and642 drawing layers. Hiding all cylinder walls produced16.7/16.7ms and336 drawing layers. Changing only fixed-background attachment produced33.4/66.7ms at1x, and50/66.8ms at4x. At4x the baseline median stayed49.9ms and removing walls stayed16.7ms. No room-state updates, garden DOM mutations or long tasks were recorded during any scroll sample; style/layout work was negligible.

Conclusion: the evidence points primarily to compositing/rendering the many CSS3D cylinder side surfaces, including miniature habitats on cards. The previous selection-handler9.5ms to4.1ms result did not measure scrolling. First optimization candidates are flat pre-rendered/SVG habitat previews and fewer cylinder side surfaces on the board. Background attachment appears secondary. rAF intervals and Chromium layer counts are not direct GPU utilization or physical iPhone/Safari measurements; synthetic scrolling and the added spacer are experimental limitations.

Reproducible local ignored artifacts: data/qa-harmonies-performance/scroll-profile.mts and scroll-results.json; /tmp/hm-scroll-profile.log. Docker5555 health remains ok. No product changes, rebuild, main push or Vercel deployment performed for this diagnosis.
