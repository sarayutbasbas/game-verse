# Take Time presentation

Use the existing GameVerse header, room menu, QR, account area, turn announcements and per-device sound controls used by Harmonies and Critter Kitchen. Thai body typography inherits the installed Thai font; Georgia is reserved for the English title and large card numerals.

Palette: Prussian blue #0d2837, deep teal #214655, icy parchment #d6eced, antique gold #e2bf70, violet from generated clock artwork. The single visual focus is a circular astronomical clock with six consistently ordered actionable sectors. Desktop places the team and rules to its right; phones stack these and show a scrollable private hand with explicit card/segment/face-up confirmation. Color is paired with a sun or crescent and Thai suit label. No emoji substitutes for game pieces.

Original generated artwork: cover, solar texture, lunar texture, clock. All 24 faces use these textures with crisp HTML numerals, not generated text. The same textures create backs that reveal only suit. Ring, needle, eye quota and bonus pips are native UI geometry to remain readable and accessible at small sizes. Prompt/source/output provenance is in asset-manifest.json. A separate transparent three-quarter box mockup uses the same lobby-box path convention and camera angle as Harmonies; the original flat cover remains available as artwork.

Responsive 320px phone, 390px touch controller, 1024px iPad and desktop. Native buttons with visible focus, modal guide/owner recall, manual resolution, reduced motion. No local animation/sound changes the game state. Music reuses the existing synthesized ambient score and independent volume/mute manager; no third-party music files.
