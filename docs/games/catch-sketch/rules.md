# Catch Sketch — ภาคหลัก + ชุดคำไทยสร้างใหม่

ใช้กติกาภาคหลัก Mandoo Games คู่มือ ©2021 (เกมวางจำหน่าย 2022, หรือชื่อ Doodly Quickly) สำหรับ 3–6 คน ไม่รวมภาค Magic Hat. ภาพและคำไทยสร้างใหม่ 100 คู่ / 200 คำ ไม่อ้างว่าเป็นสำเนาชุดคำทางการ ค่าเริ่มต้นคำง่ายเพื่อให้เริ่มเล่นสะดวก เลือกคำท้าทายในห้องรอได้

## กติกาหลักที่ใช้

1. ผู้เล่น 3–6 คน เลือกผู้เริ่มที่อายุน้อยสุดในห้องรอ ผู้เริ่มเป็นคนทาย คนที่เหลือวาด ตามเข็มนาฬิกาเมื่อจบรอบ ผู้เล่นบนเว็บจัดลำดับตามการเข้าห้อง; เลือกผู้เริ่มเองได้
2. ทุกรอบทุกคนกดพร้อมก่อนคำเปิด คนทายไม่เห็นการ์ดหรือคำ ผู้วาดทุกคนได้รับคำเดียวกัน วาดส่วนตัวพร้อมกัน ห้ามตัวหนังสือและตัวเลข
3. มีโทเคน 1 ถึงจำนวนผู้วาด โทเคน 1/2 หงาย ที่เหลือคว่ำ คนแรกที่เสร็จเลือก 1 หรือ 2 ได้และหยุดวาด คนที่สองรับหมายเลขหงายที่เหลือพร้อมสั่งทุกคนหยุด ผู้ที่เหลือสุ่มเลขคว่ำด้วย RNG ของเซิร์ฟเวอร์ ไม่เรียงจากคนวาดเสร็จคนที่สามเป็นต้นไป
4. เมื่อเล่น **3 คน** คนแรกเสร็จทำให้ทุกคนหยุดทันที อีกคนได้รับหมายเลขที่เหลือ คนแรกยังเลือกหมายเลข 2 ได้
5. เปิดกระดานตามหมายเลขจากน้อยไปมาก คนทายเห็นภาพที่เปิดก่อนหน้ารวมกับภาพใหม่ได้ 4–6 คนทายได้ภาพละ 1 ครั้ง 3 คนทายได้ภาพละ 2 ครั้ง ถ้าถูกหยุดรอบทันที คนทายและเจ้าของภาพล่าสุดได้คะแนนเท่ากัน ภาพลำดับ 1 ได้ 3, ลำดับ 2 ได้ 2, ลำดับ 3 ขึ้นไปได้ 1 คะแนน สำหรับ 3 คนคะแนนเป็น 3 / 1
6. เปิดจนหมดแต่ทายไม่ถูก ไม่มีใครได้คะแนนในรอบนั้น จากนั้นสลับคนทายคนถัดไป
7. เกมจบเมื่อทุกคนเป็นคนทายคนละ 3 ตา หรือผู้เล่นคนใดแตะ 20 คะแนน นับผู้ได้คะแนนรวมสูงสุดเป็นผู้ชนะ UI เว็บประกาศผู้ชนะร่วมถ้าคะแนนสูงสุดเท่ากัน ไม่สร้าง sudden death ที่คู่มือไม่ได้ระบุ

## การตัดสินคำและการปรับสำหรับเว็บ

- ผู้ทายพิมพ์แล้วกดยืนยันหนึ่งคำตอบ ไม่ใช่แชตทายได้ไม่จำกัด แมตช์คำด้วย Unicode NFC/ไม่สนใจช่องว่างและเครื่องหมายวรรคตอน หากตรงคำทายถูกอัตโนมัติ ถ้าไม่ตรงเข้าสู่การยืนยันโดยผู้วาดทั้งหมด คำที่ความหมายตรงกันหรือออกเสียงเหมือนกันตกลงร่วมกันได้ เปลี่ยนความเห็นได้จนเห็นตรงกันทุกคน ไม่มีคะแนนจาก client หรือการให้เจ้าของห้องแอบเปลี่ยนคะแนน
- ปุ่มผ่านภาพข้ามโอกาสที่เหลือของภาพนั้น เปิดภาพถัดไป (หรือจบรอบหากครบ) เป็นตัวช่วย UI ไม่ใช่การเพิ่มจำนวนครั้งในการทาย
- หลังจบรอบ เว็บเปิดเฉลยและภาพทุกคนให้ดูร่วมกันก่อนล้างรอบใหม่ เป็นช่วงดูผลงาน ไม่มีสิทธิ์แก้คะแนนหรือกลับไปทายใหม่จากภาพเหล่านี้
- เลือกระดับง่าย/ท้าทายทั้งห้องก่อนเริ่ม แทนการกลับการ์ดให้คำที่ต้องการตั้งตรงระหว่างถือการ์ด คนทายไม่เห็นคำอีกด้านหรือ ID ของการ์ดที่ใช้ ไม่รวมสำรับทางการหรือภาคเสริม
- ลำดับ 1/2 ตัดสินจากคำสั่งที่เซิร์ฟเวอร์รับตามลำดับ ไม่เชื่อ timestamp จากโทรศัพท์ เครือข่ายมีผลต่อการแย่งลำดับ ไม่มีการอ้างความยุติธรรมระดับจับเวลาที่ไม่สามารถรับประกันได้
- เมื่อ STOP เซิร์ฟเวอร์ล็อกภาพคนรับโทเคนทันที ผู้วาดที่เหลือหยุดรับเส้นใหม่และส่ง snapshot สุดท้ายได้คนละหนึ่งครั้ง ก่อนเริ่มเปิดภาพ คำสั่งวาดปกติหลัง STOP ถูกปฏิเสธ หากมีผู้เล่นหลุดจะรอให้กลับมาเก็บ snapshot ไม่ใช่สั่งจอกลางปลอมภาพแทน สิ่งที่ client วาดเป็นข้อมูลผู้เล่นเหมือนกระดานจริง ระบบไม่ได้ตรวจด้วย OCR ว่าวาดตัวอักษรหรือแอบแก้ภาพก่อนส่งหรือไม่

## กระดานและการบันทึก

รองรับ Pointer Events จากนิ้ว/ปากกา/เมาส์ วาดเส้นสีเข้ม เส้นบาง/กลาง/หนา ยางลบแบบเส้นสีขาว ย้อนกลับและล้างพร้อมย้อนคืนได้ กระดานมาตรฐานพิกัด 0–1023 จึงคงสัดส่วนเมื่อเปลี่ยนขนาดหน้าจอ ไม่ส่ง PNG ทุก pointer move และไม่เพิ่ม service ภายนอก

รูปแบบเส้น compact base32 (4 ตัวอักษรต่อจุด) สูงสุด 64 เส้น / 1,200 จุด / JSON ภาพ 6,800 bytes เพื่อให้คำสั่งเต็มอยู่ใน WebSocket maxPayload เดิม 8 KiB. UI เตือนเมื่อเต็มและให้ย้อน/ล้าง ไม่มีการเพิ่มเพดาน payload ของทุกเกมเพื่อเกมเดียว

เก็บร่างบนเครื่องเมื่อจบเส้น บันทึก server ประมาณไม่เกินหนึ่งครั้งต่อวินาที และส่งภาพล่าสุดไปพร้อมการรับโทเคน ร่างบนเครื่องไม่เก็บคำเฉลย รองรับ reload/reconnect ด้วยบัญชี/session เดิม ภาพที่เซิร์ฟเวอร์รับแล้วและ pending freeze/guess/judgement อยู่ใน durable room storage เดิม Local draft ช่วยกู้ช่วงระหว่าง autosave; เส้นที่กำลังลากแล้วปิดแท็บก่อน pointerup อาจยังไม่ถูกบันทึก

## Engine / identities / projections

`engine.ts` เป็น pure rules + injected RNG, ไม่มี canvas/network/storage. `drawing.ts` มีเฉพาะ codec และ bounded schema; canvas/SVG rendering อยู่ client. Server validate exact action fields, authenticated seat, role, phase, match-round epoch, monotonic own drawing version, available token, one final freeze snapshot, guess quota และ votes ก่อน commit

เฉพาะ ready/save/claim/freeze ของรอบเดียวกันอนุญาต revision เก่าที่ไม่ใช่อนาคต เพื่อให้วาดพร้อมกันได้ แต่ยังตรวจ epoch/phase/version/ownership ทุกครั้ง ผลการแย่ง token จัดลำดับบน server; guess/vote/next ยังตรวจ exact revision. Receipt เดิมไม่เล่นคำสั่งซ้ำ และ epoch ผูก match UUID ป้องกันคำสั่งจากเกมก่อนใช้กับ rematch

Public/guesser projection ไม่มี deck/current card ID/current answer หรือรูปที่ยังไม่เปิด Private เพิ่มเฉพาะ word ของผู้วาดในรอบนั้น, own sketch/version และ own judgement vote. ระหว่าง drawing แม้ผู้วาดอีกคนก็ไม่ได้ภาพของเพื่อน ทุกคนเห็นเพียง token/frozen/ready/score. จอกลาง public ดูอย่างเดียว Owner display ดำเนินรอบถัดไป/เริ่มใหม่ได้ แต่ไม่วาด/ทาย/โหวตแทนใคร

Restore schema1 ตรวจ pack100 ใบไม่ซ้ำ, ผู้เล่น/turn/ready, พิกัดและเพดานเส้น, โทเคนไม่ซ้ำ, phase/claims/freeze/order, คำตอบ/สิทธิ์ทายและ pending votes. Replay round ledger เพื่อยืนยันคะแนน ประวัติ การหยุดที่20/ครบ3ตา และผู้ชนะ ไม่เชื่อคะแนนที่เก็บมาโดยไม่ตรวจหลักฐาน

## ภาพและผลทดสอบ

สร้างปกกล่องโปร่งใส ภาพกระดาน/ปากกา/โทเคน และหลังการ์ดด้วย built-in image_gen บันทึก WebP 3 ไฟล์ประมาณ192 KiB ใน `public/art/catch-sketch/` พร้อม [พรอมป์ต์และ source paths](assets.json). หน้าไพ่คำเป็นข้อความ HTML; กระดานและโทเคนโต้ตอบวาดด้วย canvas/SVG/CSS ไม่ใช้รูป screenshot แทนการเล่น

ผลที่รันจริงของ pure rules, actual HTTP/WS/cold recovery, browser touch/mouse และ Docker อยู่ใน `docs/progress.md`. ไม่อ้างการทดสอบ Safari หรือ stylus บนฮาร์ดแวร์จริงจนกว่าจะทดสอบ
