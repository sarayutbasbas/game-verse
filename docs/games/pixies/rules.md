# Pixies — ภาคหลัก Bombyx 2024

แหล่งตรวจ 2026-10-15:
- [คู่มือ EN ทางการ](https://studiobombyx.com/assets/PIXIES_rulebook_EN.pdf), ดาวน์โหลด PDF และตรวจภาพจริง โดยเฉพาะ Case3 ที่ต้องคว่ำ (ข้อความค้นหาอ่านผิดเป็นหงาย).
- [หน้าเกม FR](https://studiobombyx.com/jeu/pixies/) และ [press sheet EN](https://studiobombyx.com/assets/PIXIES_fichedepresse_EN.pdf): 2–5 คน. หน้าเกม EN พิมพ์ 2–4 ต่างจาก FR/press sheet; ใช้ขอบเขตชุดภาคหลัก 2–5. ไม่ใช้จำนวน 6 คนของ BGA ที่รวมภาคเสริม.
- Catalog ข้อเท็จจริงเทียบ [CardManager ใน adaptation โดย thoun](https://github.com/thoun/pixies/blob/main/modules/php/CardManager.php), ซึ่ง [BGA ยืนยันว่าได้รับอนุญาตจาก Bombyx/ผู้ออกแบบ](https://en.boardgamearena.com/news?id=761). ใช้เฉพาะข้อเท็จจริงชิ้นส่วน ไม่คัดลอก implementation หรือ artwork. ตรวจเฉพาะ CARDS ภาคหลัก ไม่รวม Flower Power/Little Giants. ไม่พบ FAQ/errata แยกบนหน้าเกม/หน้าคู่มือผู้จัดพิมพ์ ณ วันที่ตรวจ.

70 ใบ: สีฟ้า เขียว เหลือง แดง สีละ16 และหลายสี6. จำนวนเลข1–9:5,6,8,10,12,10,8,6,5. รายการทุกใบอยู่ [catalog.json](../../../src/games/pixies/catalog.json), stable ID คือสี+ลำดับภายในสี, ไม่ใช่ลำดับสำรับ. perColor หมายถึงเกลียวต่อไพ่หงายสีนั้น รวมตัวเองและหลายสี.

สับครบ70ใบ เลือกผู้เริ่มสุ่ม เปิดกลางเท่าจำนวนคน. เลือกตามลำดับที่นั่ง เมื่อทุกคนเลือกแล้ว คนเลือกท้ายเริ่มชุดต่อไป. สองคนเปิด4ใบ สลับ A B A B. เช็กจบรอบหลังเลือกครบคู่แรกได้ถ้ามีสวนเต็ม (เหลือกลาง2ใบ) เพื่อให้จำนวนเลือกเท่ากัน.

ช่อง1–9เรียงซ้ายไปขวาบนลงล่าง. ช่องเลขตรงว่าง:วางหงาย; ถ้ามีคว่ำอยู่ วางทับและยืนยัน. มีหงายเดี่ยว:เลือกเก็บใบเดิมหรือใบใหม่หงาย อีกใบคว่ำใต้. ช่องยืนยันแล้ว:ต้องวางใบใหม่คว่ำในช่องว่างอื่น ห้ามคว่ำใต้หงายเพื่อยืนยันฟรี. คว่ำเดี่ยวไม่ให้แต้มในภาคหลัก และไม่มีการเลือกเปิดดูหลังคว่ำ. Projection ส่งเพียง boolean หลังคว่ำ ไม่ส่ง ID/หน้า แม้ให้เจ้าของ. ไม่มีมือลับ.

จบรอบเมื่อมีคนครบ9ช่อง หลังทุกคนเลือกครบเท่ากัน. เก็บคะแนนแยก:เลขของใบหงายที่ยืนยัน + เกลียว + พิเศษตามสี − กากบาท + กลุ่มสี. นับทุกใบหงายแม้ยังไม่ยืนยัน. กลุ่มติดด้านเดียวกันอย่างน้อย2ใบ ไม่ติดทแยง. หลายสีเป็นทุกสีพร้อมกัน แต่ไม่เชื่อมคนละสีเป็นกลุ่มรวม; คิดเฉพาะกลุ่มใหญ่ที่สุดหนึ่งกลุ่ม คูณ2/3/4ตามรอบ.

พักผลแล้วผู้เล่นหรือผู้สร้างห้องกดเริ่มรอบต่อไปจาก popup (UX เว็บเพิ่ม). รวมทุกใบกลับสับใหม่ คนวางท้ายรอบก่อนเป็นผู้เริ่ม. เล่น3รอบ รวมคะแนนสูงสุดชนะ ถ้าเท่ากันชนะร่วมกัน ไม่มี tie-breaker เพิ่ม. Host เริ่มแมตช์ใหม่หลังจบเท่านั้น.

กรณีสำรับไม่พอเปิดชุดใหม่: PDF ไม่กล่าวถึงแยกไว้ แต่ adaptation ที่ได้รับอนุญาตจากผู้จัดพิมพ์มี [EndTurn](https://github.com/thoun/pixies/blob/main/modules/php/States/EndTurn.php) ตรวจสำรับเหลือน้อยกว่าจำนวนผู้เล่นแล้วจบรอบหลังชุดเลือกครบ. เว็บใช้แนวทางนี้เป็นแหล่งเสริมอย่างชัดเจน ไม่อ้างว่าเป็นข้อความใน PDF. สองคนถ้าเหลือ2ใบ เปิดเป็นคู่สุดท้ายและเลือกคนละครั้ง; ไม่สร้างหรือสับไพ่ที่อยู่ในสวนกลับมา. เพิ่ม fixture5คนที่ใช้ครบ70ใบแต่ทุกสวนมี7ช่อง เพื่อยืนยันว่ากรณีนี้เป็นไปได้และจบรอบโดยไม่ค้าง.
