# อัจฉริยะข้ามโต๊ะ — กติกาเว็บ

- ผู้เล่น 2–20 คน ค่าเริ่มต้น 10 ข้อ ปรับได้ 1–500 ข้อ
- ทุกคนเห็นโจทย์เดียวกัน แล้วเลือก “จริง” หรือ “เท็จ” และเดิมพัน 1–5 คะแนนจากมือถือ
- คำตอบและแต้มเดิมพันเป็นส่วนตัวระหว่างตอบ จอกลางเห็นเพียงจำนวนคนส่ง
- เมื่อทุกคนตอบแล้ว เปิดเฉลยพร้อมแหล่งอ้างอิงและแจกคะแนนพร้อมกัน
- ตอบถูกเพิ่มคะแนนตามเดิมพัน ตอบผิดลบเท่ากัน
- ข้อสุดท้ายเลือกเดิมพันคะแนนสะสมทั้งหมดได้เมื่อคะแนนปัจจุบันมากกว่า 0 การตอบถูกบวกคะแนนจำนวนเท่าที่มี (คะแนนจึงเพิ่มเป็นสองเท่า) การตอบผิดลบคะแนนทั้งหมดจนเหลือ 0 ถ้าคะแนนเป็นศูนย์หรือติดลบยังเดิมพันปกติ 1–5 คะแนนได้ แต่ใช้ all-in ไม่ได้
- เมื่อครบจำนวนข้อ ผู้เล่น 5 อันดับคะแนนสูงสุดชนะ หากเสมอที่อันดับ 5 ทุกคนที่เสมอชนะร่วมกัน
- ผู้สร้างห้องกดไปข้อถัดไปหลังเปิดผลแต่ละข้อ

คลังมี 500 ข้อความจริง/เท็จไม่ซ้ำกัน แบ่งเป็น 250 ข้อเท็จจริงที่แต่ละข้อมีข้อความจริงและข้อความผิดคนละแบบ สุ่มรายการไม่ซ้ำภายในเกมหนึ่งเกม เฉลยและคำอธิบายไม่ถูกส่งไปยังอุปกรณ์ใดก่อนครบคำตอบ
