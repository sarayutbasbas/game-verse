# Jaipur — Space Cowboys base game, ©2019, two players

Primary source: [Space Cowboys official English rulebook](https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/11/Rules-JAIPUR-12x17-Version-EN_BD.pdf) linked from [publisher product page](https://www.spacecowboys-games.com/game/jaipur/), inspected2026-10-15. URL upload2025/11 is hosting date; copyright/edition is2019 (Vincent Dutrait). User supplied three reference photos include different artwork printings; runtime creates original art and does not mix component rules.

55 finite cards: diamond6, gold6, silver6, cloth8, spice8, leather10, camel11.38 goods tokens,18 bonus tokens,1 camel token(5 rupees),3 seals. Setup: set aside3 camels for market; shuffle remaining52; deal5 each; draw2 into market; move initial hand camels into own face-up stacked herd. Thus market5, remaining deck40, total hand+herd10. Pick initial starter; loser of previous round starts next.

Goods stacks highest first, all remaining values visible. Collected tokens stacked; cumulative money not public midround. Three bonus piles shuffled independently; category/count public, remaining values/order hidden; drawn bonus value owner-only until round scoring. The official rulebook does not entitle an opponent to an exact herd count (p7). **User-requested web variant, 2026-10-15:** expose exact herd counts for both seats and the public display at all times. This changes information visibility, not movement, trading, scoring or settlement. Project only the count, never an opponent herd card-ID array; during round do not return opponent hand identities, token faces, subtotal or total. Public events describe committed market action/sale type/count and visible goods payouts, never private draws or bonus value; herd totals are public in the explicitly requested web variant. Goods income can be remembered from public play, but UI does not add running opponent totals. Discard top and count public (physical face-up pile); no inspection of older discard identities added.

Turn: TAKE single non-camel (hand<=7 after, refill); TAKE all market camels into herd (no hand cap, refill); EXCHANGE at least2 non-camel market cards for equal total of own hand goods/camels. Cannot take camels in exchange, cannot take and return the same goods type, hand after<=7; market stays5, no deck draw. Or SELL any positive count of one goods type from own hand, diamond/gold/silver minimum2 even if tokens left1. Discard sold cards, take highest remaining goods tokens up to sold count, then category3/4/5+ bonus if available. No invented tokens/refill/discard recycling. One action atomic; never take+sell together.

Round ends when3 goods stacks depleted, or a refill cannot reach5. Merely emptying deck exactly while completing market does not end round. Finish action and award any bonus before settlement. Camel5 to strictly larger herd; equal herds neither. Reveal collected token values; score goods+bonus+camel, never unsold hand. Highest score wins; tied score: most bonus tokens, then most goods tokens. Award exactly1 seal to winner; first2 seals wins match. Summary remains visible before next-round action resets components with fresh shuffle; previous loser starts.

## Explicit web ruling approved by user2026-10-15

Publisher text does not resolve score+bonus count+goods count all tied. User approved: record a drawn round, no seal, and require an explicit mutually agreed starter selection before next round. Do not label this rare edge as an official extra tie breaker. No random winner or forced winner. A match may have more than3 rounds if this occurs; no invented victory condition.
