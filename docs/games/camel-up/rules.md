# Camel Up — กติกาที่ใช้ใน MVP

เลือก Second Edition (2018), อ้างอิงคู่มือภาษาอังกฤษ Lookout reprint 2024:
https://www.lookout-spiele.de/upload/en_camelup.html_CamelUp_PZE30070_Rules_EN_WEB_240305.pdf
อ่านคู่มือครบหน้า setup, overview, actions, scoring และ partnership วันที่ 2026-10-14. บทความประกอบตามที่ผู้ใช้ให้: https://thaiboardgamers.com/camel-up-board-game-how-to-play-setup-beginner/

รองรับ 3–8 คน ตามคำตอบผู้ใช้ ไม่มีโหมด 2 คน ไม่มีการผสมกติกาฉบับแรก

- ลู่วิ่ง 1–16, ฟ้า/เขียว/เหลือง/ม่วง/แดง, อูฐบ้าดำ/ขาว. Array stack เรียงล่าง→บน; อันดับเรียงตำแหน่งมาก→น้อย และบน→ล่าง ข้ามอูฐบ้า
- เริ่มเงิน 3, การ์ดลับสีละใบ, ป้ายคนละหนึ่ง; บัตรเลกสีละ 5/3/2/2. Server สุ่มตำแหน่งอูฐแข่ง 1–3 และสุ่มลำดับ stack (คู่มืออนุญาตจัด stack ตามใจ). อูฐบ้าแต่ละตัวสุ่ม 14–16; ตัวที่วางทีหลังอยู่บนถ้าช่องเดียวกัน
- จอกลางเลือกผู้เริ่ม (แนะนำอายุน้อยที่สุดตามคู่มือ); ลำดับผู้เล่นเป็นลำดับเข้าห้องแทนตำแหน่งนั่งจริง. ทุก action ปกติเลื่อนไปผู้เล่นถัดไป
- เลือกหนึ่ง action: หยิบบัตรเลก, วาง/ย้ายป้าย, รับบัตรพีระมิดแล้วสุ่มเต๋า, ลงการ์ดผู้ชนะ/ผู้แพ้ หรือจับคู่เมื่อ 6+ คน. สีที่ใช้ลงการ์ดไปแล้วใช้ฝั่งอื่นไม่ได้
- สุ่มหนึ่งจากเต๋าที่ยังเหลือทั้งหมด 6 ลูก (5 สี+เทา), เลข 1–3 เท่าโอกาสกัน; เทา 6 หน้าแบ่งขาว/ดำ. จบเลกหลังสุ่มลูกที่ 5 จึงมี 1 ลูกไม่ได้ออกเสมอ
- ขยับอูฐพร้อมทุกตัวบนหลัง ทิ้งตัวล่างไว้; landing ปกติอยู่บน stack. อูฐบ้าขยับสวนทาง. เทาเลือกตัวที่แบก racing หากมีเพียงตัวเดียว; ถ้าอูฐบ้าซ้อนติดกันเลือกตัวบน; กรณีอื่นตามสีเต๋า
- ป้ายวางช่องว่าง 2–16 ไม่มีอูฐหรือป้าย และไม่ติดป้ายผู้อื่น. ย้ายได้แต่ต้องช่องใหม่. ป้ายเชียร์เพิ่ม 1 ในทิศเคลื่อนของตัวนำและลงบนกอง; โห่ถอย 1 และลงใต้กอง. เจ้าของรับ 1 ทันที. ป้ายอยู่จนจบเลก. ไม่มีป้ายติดกันจึงไม่ chain effect
- เลก: รวม reward ทุกบัตรก่อนปรับเงินครั้งเดียว; ที่หนึ่งตามมูลค่าบัตร, ที่สอง +1, อื่น -1; พีระมิด +1. เงินต่ำสุด 0. คืนบัตร เต๋า ป้าย พันธมิตร แล้วผู้เล่นถัดจากคนทอยคนสุดท้ายเริ่มเลกใหม่
- พันธมิตรต้องทั้งคู่ยังว่าง ปฏิเสธไม่ได้ จับคู่ตัวเองไม่ได้; ตอน settlement เลือกคัดลอกหนึ่งบัตรของคู่ (รวมพีระมิด) หรือไม่เลือกเลย แต่ละคนเลือกอิสระ ไม่ยึดบัตรจากคู่ ไม่จำเป็นต้องเลือกผลสูงสุด
- ข้ามเส้นชัยด้าน >16 หรือ <1 จบทันที รวมอูฐบ้า; ไม่เดินป้ายต่อหลังข้าม. racing ที่ถูกแบกย้อนข้ามเส้นเป็นกลุ่มท้ายสุด. จัดอันดับ stack แบบเดิม. คิดเลกสุดท้ายก่อน final
- เปิดกองทายผู้ชนะก่อนแล้วผู้แพ้ ตามลำดับลงการ์ด: ถูกคนที่ 1/2/3/4/5+ รับ 8/5/3/2/1; ผิด -1 แต่เงินไม่ต่ำกว่า 0. เงินมากสุดชนะ; เสมอชนะร่วม

## Product policy (ไม่ใช่กติกากล่อง)

ชื่อสีฟ้าใน UI ใช้แทนอูฐ blue; เงินทุกคนแสดงจำนวนตรง ๆ เพื่ออ่านจอกลางง่าย (คู่มืออนุญาตซ้อนเงินโดยไม่ต้องบอกยอด). ผู้สร้างเริ่มเกมจากจอกลาง; phone session แยกจาก host. หลุดไม่ข้ามตาอัตโนมัติ ผู้เล่นกลับด้วย token เดิม; ถ้าไม่กลับให้สร้างห้องใหม่. ห้องเก็บถาวรผ่าน SQLite ใน dev / Postgres บนเว็บจริง กู้หลัง restart ได้เมื่อใช้ฐานข้อมูลและ auth secret เดิม. ห้องหมดอายุเมื่อไม่มีการเข้าร่วมจริงหรือคำสั่งสำเร็จเกิน 10 ชั่วโมง; reconnect/watch ไม่ต่ออายุ (ดู docs/platform-storage.md). MVP ไม่มี reset ระหว่างเกม/kick/skip turn เพื่อไม่ให้ host แก้คะแนนระหว่างเกม

## Fixtures ที่ต้องตรวจ

- stack กลางขยับพร้อมตัวบน; tile โห่ลงใต้; ป้ายอูฐบ้ากลับทิศและเงินเจ้าของ
- crazy ซ้อนตรงกันและแบก racing; grey ไม่ซ้ำในเลก
- 5 จาก 6 เต๋าจบเลก คืนทรัพยากร turn ถัดไป; leg net ก่อน floor 0
- partnership เลือกทั้งสองฝั่ง จบเลกครั้งเดียว; invalid choice ไม่ mutation
- final payout ลำดับถูกแยกจากผิด, floor 0, shared victory; backward finish
- engine invalid action ไม่แก้ state; server wrong turn/stale/duplicate/privacy/reconnect

Product policy เพิ่มเติม: เมื่อเกมจบ host กดเล่นอีกครั้งในห้องเดิมได้เมื่อผู้เล่นทุกคน online ใช้ผู้เล่น/session เดิม แต่เงิน การ์ด และกระดานเริ่มตาม setup ใหม่ ไม่ใช่ house rule เปลี่ยนคะแนนภายในเกม
