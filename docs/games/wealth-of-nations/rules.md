# Wealth of Nations — TableStar 2008 base game

User confirmed the 2008 hex-board edition on 2026-11-02. Base first-printing rulebook, not War Clouds/V2 or later fan/designer 3.0 restructuring. 3–6 players. Primary publisher booklet (mirror): https://www.boardgamecapital.com/game_rules/wealth-of-nations.pdf (16 pages, Copyright2008 TableStar). Also indexed at https://tesera.ru/images/items/171049/WoN_Lo_Res_Rules.pdf . Physical original components inspected via BGG image API, image IDs285944–285948 (five markets),349505 (industry geometry),349500 (reference sheet). Sources are research-only; runtime art is new image_gen illustration plus exact code geometry/text.

60 usable radius4 hexes; center forbidden. Fifteen farms and nine each of five other industries;18 flags per nation. Five cube types and purple bank industry. Full/half/third dots and all six rotations follow physical tiles. Matching partials connect same-owner same-industry blocs even without completing a dot. Different colors touching at an edge or vertex require one extra Capital per newly placed tile. No cross-owner production bonuses.

Starting snake draft:3 players4 rounds,4 players3 rounds,5/6 players2 rounds. First round industry only; five-player setup excludes duplicate Farm package2; at5/6 second round commodity only. Each industry's package is placed as one contiguous group, no conflicting dots, anywhere unoccupied except center. Each package used once; commodity packages, starting cash and stock counts match the booklet. Nation is chosen clockwise before draft; starter is server-random or host-selected, mechanically equivalent to the booklet's shuffled one-Generator selection.

Trade: one cube buy/sell or a negotiated exchange with one other nation, or pass. Passing does not drop out: only consecutive passes by everyone ends a phase. Markets have40 wells for Food/Energy/Labor and30 for Ore/Capital, initially half occupied. All printed buy/sell/barter prices are transcribed into explicit lookup tables, including the rounded integer barter figures on the Ore/Capital sheets; none are inferred from a universal midpoint formula. Empty-market barter has no printed value and is shown as a dash. Empty-market buys use printed maximum; full-market sells use printed minimum. Cubes remain publicly countable; money remains visible as a cash-pile icon but exact cash only reaches owner until final scoring, since booklet does not require revealing/counting money. Notes are public. Borrow/repay during any Trade turn without consuming the action; payouts follow literal20-minus-held-notes, repayment25, no V2 interest. Bank money/notes/automation do not run out. Production can create paper substitute cubes when physical supply is exhausted; their ledger is tracked. Future promises are recorded as table agreements, fulfilled manually through later accepted trades; the server does not interpret free text or automatically transfer future resources. The booklet does not specify an enforcement mechanism, and this UI does not claim a general official ruling on breaking promises. Atomic offer/accept revalidates both inventories; declined/canceled proposals do not consume a trade action.

Develop: Labor1 to claim adjacent own flag; separate action builds on an owned empty claim at printed resource cost; Capital1 moves up to3 industries with their flags, anywhere legal, returns redundant destination own flags. Remove all selected tiles first, then place in submitted order with per-tile forcing costs. Automate one bloc for Energy1+Capital2. Splitting an automated bloc requires selecting which resulting bloc keeps its automation; merging redundant tokens normalizes to one automated bloc. Unchanged automation remains with its bloc. Production never chains current output into costs.

Produce: each player submits powered/fed tiles, or Ore1 for a whole automated bloc. Food1 per fed tile except Farms; Energy1 per used whole bloc except Generators. Unfed partials do not contribute. All cost plans are validated against pre-production holdings and collected before any output. Each complete same-owner dot yields one cube, or30cash for banks. One production per round; public clients only get prepared status before joint resolution, owner gets own plan. Booklet allows production to occur together; shared confirmation is a web presentation of the same simultaneous costs/output.

At END of Develop check all18flags used by anyone, all60usable hexes claimed, or5industry stacks empty. Then final Produce and final Trade before score. Four points per industry plus floor(cash/10) minus3per note; ties cash, then flags, then shared victory. No invented round cap or automatic liquidation. No expansion/super-industry/war/interest/revised-market rules.
