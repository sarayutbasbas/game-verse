# Name It! — มหึหมา: local shared-device implementation

## กติกาจากผู้ใช้

2–6 คนล้อมวง ใช้อุปกรณ์เดียว ผลัดผู้เปิดการ์ด แต่ทุกคนตอบพร้อมกันด้วยเสียงจริง เกมจบหลังตัดสินใบสุดท้าย คะแนนสุนัขธรรมดา/สายจูง/กลูต้า/กอลลั่ม +1, แมว −1. สุนัขสายพันธุ์ใหม่ให้คนเรียกสายพันธุ์ถูกก่อนและให้ตั้งชื่อ; ใบซ้ำเรียก nickname; สายจูงที่เคยตั้งชื่อเรียกชื่อผู้ตั้งชื่อครั้งแรก โดยการได้รับการ์ดภายหลังไม่เปลี่ยนเจ้าของ. แมวผู้ตบช้าที่สุดรับ −1; กลูต้าผู้เร็วที่สุดรับ +1; กอลลั่มทำ action เหมือนใบก่อน คนทำถูกก่อนรับ +1.

ไม่ใช้ speech recognition หรือ microphone. เกมไม่อ้างว่าทราบตัวตนคนเปิดบนเครื่องร่วมกัน. แตะเบาที่โซนของตน ไม่ตบกลางอุปกรณ์. วงยืนยันผลและใช้ manual override ได้ ไม่มี auto-timeout แจกการ์ด.

## สิ่งที่ตรวจเพิ่ม / แหล่งอ้างอิง

ตรวจ16ตุลาคม2026: https://www.ludusproducts.com/products/name-it-dogs-edition อธิบายเกมเรียกสายพันธุ์ จำชื่อ และตอบเร็ว แต่ไม่มีสำรับหรือ edge-case rules ให้ตรวจครบ. ผลค้นหาร้านผู้จัดพิมพ์ Box & Brew แสดง Dogs Edition / Gluta Story Edition แต่ยังไม่ได้คู่มือทางการครบ จึงไม่ใช้รายละเอียดจากเกมชื่อ Name It คนละเกม.

ภาพอ้างอิงผู้ใช้ de.jpg ใช้ตรวจทิศทางภาพ/สุนัข/สายจูง, กล่อง Dogs Edition ใช้ mood/palette ไม่อนุมานจำนวนการ์ดจากรูปกล่อง. ยังไม่อ้างว่าตรงสำรับต้นฉบับ.

## สำรับเว็บ 69 ใบ (ยืนยันสัดส่วน 16 ตุลาคม 2026)

ผู้ใช้ยืนยันสุนัข12สายพันธุ์ สายพันธุ์ละ5ใบ โดยสุนัขธรรมดาและมีสายจูงรวมอยู่ใน5ใบนั้น ไม่ใช่อีก5ใบแยกกัน ชุดเว็บใช้ธรรมดา3+สายจูง2ตามสัดส่วนที่เสนอไว้ก่อนหน้า รวม60ใบ และแมว3/กลูต้า3/กอลลั่ม3 รวม **69 ใบ** สับทั้งสำรับ ไม่บังคับให้การ์ดที่เปิดสลับชนิดกัน

ชุดเว็บใช้สายพันธุ์เดิม8ชนิด: ดัชชุนด์ เฟรนช์บูลด็อก ปอมเมอเรเนียน ชิวาวา ชิบะ ปั๊ก ฮัสกี คอร์กี; เพิ่มบีเกิล ดัลเมเชียน โกลเด้นรีทรีฟเวอร์ และพุดเดิลให้ครบ12 สี่ชนิดเพิ่มเติมเป็นตัวเลือกสำหรับชุดเว็บ ไม่อ้างว่ารายชื่อหรือภาพตรงสำรับกล่องต้นฉบับ รุ่นกติกา `user-request-web-69-v1` การเริ่มเกมตรวจยอดรวมต้องตรง69

[คำอธิบายจากผู้ออกแบบบน BoardGameGeek](https://boardgamegeek.com/boardgame/436851/name-it) และ [Áurea Ediciones — Perritos / Name It!](https://www.aureaediciones.cl/perritos-name-it) ยืนยันจำนวน69; ผู้จัดพิมพ์ระบุ12สายพันธุ์ แต่ไม่มีรายการแจกแจงต่อชนิดในหน้าที่อ่าน จึงอ้างสัดส่วนจากคำยืนยันผู้ใช้ และแยกชื่อ/ภาพชุดเว็บจากคำอ้างอิงทางการ

ข้อวินิจฉัยเว็บที่ยืนยัน แยกจากคำอ้างอิงกติกาทางการ:

- กอลลั่มใบแรกกลับไปสับจนใบแรกไม่ใช่กอลลั่ม ใน engine ใช้การสุ่มแบบมีเงื่อนไขให้ใบแรกไม่ใช่กอลลั่ม ซึ่งให้การกระจายสำรับเทียบเท่าการสับซ้ำ ไม่วนสุ่มไม่สิ้นสุด
- กอลลั่มต่อกันใช้บริบทและคำตอบเดิม แม้สุนัขใบนั้นเพิ่งถูกตั้งชื่อแล้ว; หลังแมวยังแตะ แต่กอลลั่มให้ผู้ทำถูกก่อน +1
- พูดหรือแตะผิดไม่มีโทษเพิ่มเติม ให้คนในวงตกลงผู้ที่ทำถูกก่อน
- ชื่อสุนัข 1–30 ตัวอักษร ไม่ซ้ำชื่อสุนัขที่ตั้งไว้แล้วในเกมนี้
- แตะสูสีหรืออุปกรณ์รับนิ้วไม่ครบ ให้คนในวงตัดสินและยืนยัน ไม่แจกแมวอัตโนมัติ
- คะแนนรวมเท่ากันเป็นผู้ชนะร่วมกัน

## วิธีจัดการบนอุปกรณ์เดียว

Local engineเป็นแหล่งตัดสินสถานะตามคำขอผู้ใช้ซึ่งเป็นข้อยกเว้นจากroomserverของเกมออนไลน์. Match/playerIDsคงที่, nicknameและoriginalownerแยกจากผู้รับปัจจุบัน. Viewตอนแข่งขันไม่ส่ง answer/context/name mapping ไปยังDOM; การ์ดใช้ชื่อไฟล์opaqueและaltกลาง. ไม่มีการแสดงgollumactionhintก่อนเข้าขั้นตัดสิน.

การแตะเก็บได้ทุกใบเพื่อไม่ให้UIช่วยบอกคำตอบ. เมื่อวงกดตัดสินจึงแสดงผลเวลา/คำตอบที่จำเป็น และกลับไปแข่งใบเดิมไม่ได้. แตะเร็ว/ช้าต้องยืนยันก่อนให้คะแนน. รับคนละหนึ่งpointerdownต่อใบ ไม่รับนิ้วที่ค้างก่อนเปิดครบ; เวลาที่ใกล้กันถือว่าอุปกรณ์อาจตัดสินไม่ได้และต้องยืนยันด้วยคน.

การกู้เกมที่เปิดค้างอยู่จะเข้าสู่การตัดสินด้วยคน ไม่สร้างลำดับแตะย้อนหลัง. ค่าคะแนนคำนวณจากการ์ดที่ได้รับ ไม่เชื่อคะแนนที่เก็บในstorage. ทดสอบbrowseremulationไม่ใช่หลักฐานความเป็นธรรมของmulti-touchบนเครื่องจริง.
