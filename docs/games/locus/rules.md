## สำรับและแผ่นผู้เล่น

พิกัดทั้งหมดใน `src/games/locus/data.ts` เป็นข้อมูลกติกา ไม่ใช่ตำแหน่งภาพจอ เริ่ม (0,0) บนซ้าย x ไปขวา y ลงล่าง ตรวจจากแผ่น publisher และตาราง reference 8×6 ในคู่มือ Tucker ตัวจริง

48 ใบ: สีเหลือง ม่วง แดง เขียว ฟ้า สีละ 8 ใบ = 40 และรุ้ง 8 ใบ รหัส `lc-แถว-สี` แถว1–8 สี1–6 ตามลำดับข้างต้น ห้าสีปกติมี U5,T5,Z5,W5,F5,L5,I3+เหรียญ,L3+เหรียญ; รุ้งเป็น T4 สองใบ,L4 สองใบ,S4 สองใบ,domino2+เหรียญสองใบ สองใบที่รูปเหมือนกันยังเป็นคนละการ์ด รวมเหรียญพิมพ์12ใบ รวมช่องรูปทรง208ช่อง orientation เป็นตัวแทนหนึ่งแบบ หมุนและสะท้อนได้ทั้งหมด

แผ่นรวม213ช่องและ35โบนัส (โซนละ7):
- เหลือง6×6 เริ่มได้ทุกช่องแถวล่าง คะแนนแถวบนลงล่าง12,12,12,10,10,8
- ม่วง7×7 มีช่องขอบหนา8จุด: (0,0),(6,0),(3,1),(1,3),(5,3),(3,5),(0,6),(6,6)
- แดง4กลุ่มแยกขาด7/7/8/9ช่อง คะแนน12/12/14/16; รูเว้าเป็นช่องที่วางไม่ได้ ไม่มีเงื่อนไขเริ่ม/ติด
- เขียว31ช่อง พิกัดกราฟใน data.ts เริ่ม(3,4) ปลาย7จุด:(3,0),(0,1),(6,1),(0,5),(0,7),(3,8),(6,7)
- ฟ้า3×22 เริ่มทุกช่องแถว21 เส้นคะแนน row17=8,row13=16,row9=24,row6=32,row3=40,row0=50

โบนัสพิมพ์ทั้งหมดและพิกัดรูปทรงทุกใบระบุ machine-readable ใน `data.ts`; ไม่มีสุ่มแต่งผังหรือสุ่มรูปทรงเพิ่มเติม การแสดงผล SVG อ่านไฟล์เดียวกับ server

## Setup / รอบ / ชุดการ์ด

แต่ละคนเริ่ม1เหรียญ ผู้วันเกิดใกล้ถึงที่สุดเริ่ม: เจ้าห้องเลือกชื่อโดยไม่เก็บวันเกิด เปิด n+1 การ์ด เลือกคนละ1ตามเข็มนาฬิกาจากผู้ถือดาว แต่ละคนสามารถกากบาท/แก้โบนัสของตัวเองระหว่างที่คนถัดไปเลือกได้ คำสั่งเลือกการ์ดยังต้องตามลำดับ

**หนึ่งรอบมี n ชุดการ์ด** ทุกคนต้องได้เป็นผู้เลือกแรกครบหนึ่งครั้ง: 2คน8รอบ=16ชุด;3คน5รอบ=15ชุด;4คน4รอบ=16ชุด;5คน3รอบ=15ชุด หลังทุกคนจัดการรูปทรง/โบนัส/เหรียญและกดจบชุด จึงทิ้งการ์ดกลางทั้งชุด เลื่อนดาวหนึ่งคน เปิดชุดใหม่ เมื่อกองจั่วว่าง สับกองทิ้งแล้วจั่วต่อ ไม่เอาการ์ดชุดที่ยังใช้มาสับ

## วางและโบนัส

รูปทรงทั้งหมดต้องอยู่ในโซนสีเดียวกัน ใช้ครบทุกช่อง ไม่ทับของเดิม หมุน0/90/180/270และสะท้อนได้ รุ้งเลือกโซนใดก็ได้ ในเหลือง/ม่วง/เขียว/ฟ้า ต้องมีอย่างน้อยหนึ่งช่องทับช่องเริ่มขอบหนา **หรือ** ติดช่องที่กากบาทแล้วแนวตั้ง/นอน แดงวางที่ว่างในกลุ่มใดก็ได้ รูปทรงห้ามข้ามรู/ช่องนอกแผ่น

รับเหรียญบนการ์ดทันทีที่หยิบ ถ้าไม่ใช้รูปทรงการ์ดหลัก ทิ้งรับ2เหรียญเพิ่ม (การ์ดเหรียญจึงได้รวม3) โบนัสเกิดเมื่อกากบาททับตำแหน่งนั้นครั้งแรก: เหรียญ1; dominoสี2ช่องต้องติดและใช้ครบ; รุ้งเดี่ยว1ช่อง โบนัสต่อโบนัสได้ ไม่ต้องติดกับรูปทรงที่ให้โบนัส แต่ต้องผ่านเงื่อนไขโซนนั้นตามปกติ

คู่มือใช้คำว่า may สำหรับโบนัส: เว็บให้ผู้เล่นเลือกจัดการโบนัสที่รอใบใดก่อนก็ได้ หรือกดไม่ใช้ ไม่มีเก็บข้ามชุด ไม่มีเหรียญปลอบใจจากโบนัส/รูปทรงที่ซื้อ กำหนดเป็นการจัดลำดับ interface ของเว็บ ไม่อ้างเป็น timing FAQ เพิ่มเติม โบนัสทุกชิ้นมี stable ID และ source-cell; source เดิมไม่แจกซ้ำ การเปลี่ยนสี/วาง/รับโบนัสเป็นธุรกรรมเดียว ปุ่มยกเลิก preview ไม่ใช้เหรียญ

## เหรียญ

ใช้ในตาของตนก่อน/หลังเลือกและระหว่างจัดโบนัสได้; เว็บเปิดสิทธิ์ตั้งแต่เป็นผู้เลือกปัจจุบันจนกดจบชุด ผู้เล่นที่ยังไม่ถึงคิวไม่ใช้ข้ามคิว
-1: เปลี่ยนสีรูปทรงการ์ดหรือโบนัส จ่ายตอนยืนยันจริง รุ้งไม่ต้องจ่าย
-2: รับสองรูปทรงเดี่ยวรุ้ง วางต่างโซนได้ แต่ต้องผ่าน start/adjacency
-3: หลังทุกคนเลือกแล้ว ใช้รูปทรงการ์ดเหลือโดยไม่หยิบออก ทุกคนใช้ได้คนละครั้งต่อชุด ได้เหรียญถ้าพิมพ์บนการ์ด และจ่ายอีก1เพื่อเปลี่ยนสีได้

ไม่มีเพดาน22เหรียญจากจำนวนวงกลมที่พิมพ์ ใช้ยอดคงเหลือ+ledgerได้รับ/จ่าย ไม่ทำเหรียญติดลบ ไม่ refund เมื่อผู้เล่นเลือกไม่ใช้รูปทรงที่ซื้อแล้ว

## คะแนนและจบ

เหลืองบวกเฉพาะแถวเต็ม ม่วงนับเครือข่ายกากบาทที่เชื่อมขอบหนาได้จำนวนมากที่สุดเท่านั้น ถ้าอย่างน้อย2จุด ได้6ต่อจุด (จุดเดียว0) แดงบวกกลุ่มที่ครบ เขียวปลายละ8เฉพาะมีเส้นกากบาทเชื่อมศูนย์กลาง ฟ้านับขั้นสูงสุดที่ถึง/ผ่าน ไม่บวกขั้นสะสม ไม่ต้องเต็มแถว รวม5สีแล้วบวกค่าต่ำสุดหนึ่งครั้งอีกที

จบเมื่อชุดสุดท้ายทุกคนไม่มี pending effects และยืนยันใช้เหรียญเสร็จ Server บันทึกผลสี/breakdown/ผู้ชนะครั้งเดียว ดูใหม่หรือ animation ไม่คิดซ้ำ

คู่มือ Tucker EN ใช้ “can play an extra round” เมื่อเสมอ (WWGเขียนคำสั่งplayextra): เลือกฉบับ Tucker ให้แสดงผู้ชนะร่วมและเจ้าห้องเลือกต่ออีก1รอบเต็ม nชุดบนแผ่น/เหรียญเดิมได้ ถ้าเสมออีกยังต่อได้ ไม่ใช้เหรียญเป็น tie-break สมมุติ ไม่บังคับรีเซ็ต เริ่มเล่นใหม่เท่านั้นจึงแจกสำรับ/แผ่นใหม่

## Visibility / integration
