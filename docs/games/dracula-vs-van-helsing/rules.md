## กติกาทางการที่ตรวจแล้ว

32 ใบ: แดง เหลือง เขียว ม่วง สีละเลข 1–8 หนึ่งใบต่อคู่สี/เลข; 2 ที่วางการ์ด, กระดานเมือง 5 เขต, กระดานอันดับสี/4 token, 20 คน/แวมไพร์, 12 HP, เรือบอกรอบ

เลือกบทบาทคนละตัว ใช้ตลอดเกม. ทุกเขตเริ่มมนุษย์ 4 คน Dracula เริ่ม HP 12 รอบ 1. สุ่มอันดับสี 4 สี สีสูงสุดคือทรัมป์. สับทั้ง 32 ใบ แจกฝ่ายละ 5 ใบ วางตามลำดับจั่วตรงเขต 1–5 (จุดกำกับ 1–5 ตามคู่มือ) ห้ามเรียงใหม่เอง. Dracula เริ่มทุกรอบ

ในตา: จั่ว 1 ใบ แล้วเลือกทิ้งใบที่จั่ว หรือแทนที่การ์ดของตนในเขตหนึ่งและทิ้งใบเดิม. กระตุ้นความสามารถของใบที่ทิ้ง (ต้องทำถ้าทำได้). การเปิดเผยเป็นสถานะของตัวการ์ด ตามการ์ดไปเมื่อสลับ/แลก และคงอยู่จนทิ้ง ไม่ใช่สถานะช่อง. ใบบนกองที่เปิดแล้วจั่วไปยังคงเปิดตามตัวอย่างคู่มือ

| เลขที่ทิ้ง | ผล |
|---|---|
| 1 | เปิดการ์ดของตนหนึ่งใบ |
| 2 | เปิดใบบนสุดของกองจั่ว |
| 3 | เปิดการ์ดคู่แข่งหนึ่งใบ |
| 4 | สลับการ์ดของตนสองใบ |
| 5 | เล่นอีกตา รวมถึงตาสุดท้ายหลังอีกฝ่ายขอจบรอบ |
| 6 | แลกการ์ดสองฝ่ายในเขตเดียวกัน |
| 7 | สลับ token สีทรัมป์กับอีกหนึ่งสี |
| 8 | ทิ้งได้เมื่อกองทิ้งมีอย่างน้อย 6 ใบอยู่แล้ว จบรอบทันที คู่แข่งไม่มีตาสุดท้าย |

ก่อนจั่ว หากกองทิ้งมีอย่างน้อย 6 ใบ สามารถขอจบรอบแทนการจั่ว/ทิ้ง. อีกฝ่ายได้ตาสุดท้าย (การ์ด 5 ต่อได้). กองจั่วหมดก็จบรอบหลังเล่นและทำผลของการ์ดที่จั่วสุดท้ายครบ; ผลเปิดกองจั่วทำไม่ได้เมื่อไม่มีใบเหลือ

เปิดการ์ดทั้งสองฝ่าย ตัดสินเขต 1 → 5 ตามทิศลูกศรในคู่มือ. หากฝ่ายเดียวมีทรัมป์ ฝ่ายนั้นชนะ; ทรัมป์ทั้งคู่ใช้เลข; ไม่มีทรัมป์ใช้เลข เลขเท่ากันใช้ลำดับสีที่สูงกว่า. เสมอทั้งสีและเลขไม่เกิดในสำรับหนึ่งชุดและถือว่า state ผิด invariant ไม่สร้างกติกาผลเสมอขึ้นมา

Dracula ชนะเขตเปลี่ยนคน 1 คนเป็นแวมไพร์ในเขตนั้น. Helsing ชนะเขตลด HP Dracula 1. ตรวจหลัง **แต่ละเขต**: HP 0 → Helsing ชนะ; เขตมีแวมไพร์ 4 → Dracula ชนะทันที และไม่คิดเขตที่เหลือ. หากครบทุกเขตในรอบ 5 ยังไม่ชนะ Dracula ชนะเพราะรอดชีวิต

ถ้ายังไม่จบ เพิ่มรอบ สับ **ทั้ง 32 ใบใหม่** แจก 5 ใบตามลำดับ. HP แวมไพร์ และอันดับสีหลังผลการ์ด 7 คงเดิม (คู่มือสั่งสับการ์ด ไม่สั่งสุ่มอันดับสีใหม่)

## ข้อกำหนดเว็บ / UI ที่เพิ่มโดยไม่เปลี่ยนผลกติกา

- เลือกบทบาทและพร้อมใน lobby; เริ่มโดย host หลังสองคนออนไลน์และพร้อม
- จั่ว → เลือกใบที่จะทิ้ง → เลือกเป้าหมายความสามารถ เป็นหลายคำสั่งในตาเดิม ไม่มีคนอื่นแทรกตาระหว่างขั้นตอน
- effect เปิดการ์ดให้เลือกใบที่ยังไม่เปิดเท่านั้น หากเปิดครบแล้วข้ามเพราะไม่มีข้อมูลให้เปิดเพิ่ม
- แสดงเขตเป็นหมายเลข 1–5 เรียงซ้ายไปขวาตามจุดในคู่มือ ไม่สร้างชื่อ/ความสามารถเขตใหม่
- รูปแบบเว็บที่ผู้ใช้อนุมัติ: จบรอบแต่ละคนแตะเปิดเฉพาะไพ่ฝั่งตัวเองทีละใบ เลือกเขตใดก่อนก็ได้ ใบที่เปิดอยู่แล้วนับว่าเปิดแล้ว. Server คำนวณผลตามกติกาเขต 1–5 แต่ public racks/result/event ส่งเฉพาะหน้าที่เปิดแล้ว และคะแนนแสดงเฉพาะลำดับเขตที่เปิดครบคู่ต่อเนื่อง. ครบทั้งสิบใบจึงอนุญาตทั้งสองกด “พร้อมรอบถัดไป” หรือ host เล่นใหม่หากจบเกม. เป็นขั้นตอนนำเสนอเพิ่มเติม ไม่เปลี่ยนผู้ชนะ/ลำดับตัดสิน. ผลเก่าที่บันทึกก่อนมีระบบนี้ถือว่าเปิดครบ เพราะเคยเผยแพร่แล้ว.
- การเลือก target ใช้ตำแหน่ง 0–4 ใน protocol; UI ใช้เขต 1–5
- สำรับสุ่ม server ให้ Dracula จั่ว 5 ใบก่อนแล้ว Helsing 5 ใบ โดยทั้งสองฝ่ายไม่เลือก/เปลี่ยนลำดับ ผลแจกเทียบเท่าการแจกจากสำรับที่สับอย่างสม่ำเสมอ
