# Just One — ภาคหลัก 2018 / ชุดคำไทยสำหรับเว็บ

แหล่งกติกาหลัก: [คู่มือภาษาอังกฤษ Repos Production ©2018](https://cdn.svc.asmodee.net/production-rprod/storage/downloads/games/justone/jo-en01-rules-1612262916hCy2w.pdf), หน้า 1–4 ตรวจ 1 พฤศจิกายน 2026. [หน้าผู้จัดพิมพ์](https://www.rprod.com/en/games/just-one) ยืนยัน 3–7 คน / ประมาณ 20 นาที. เลือกฉบับ 2018 โดยตั้งใจ: **เฉพาะ 3 คน** ให้เพื่อนแต่ละคนเขียน 2 คำใบ้ ไม่ใช้กติกาฉบับ Refresh ที่เพิ่มรูปแบบให้ 4 คนด้วย

เกมร่วมมือ 3–7 คน สุ่ม 13 ใบจากชุดคำไทยคละหมวดที่สร้างใหม่ 100 ใบ ใบละ 5 คำ รวม 500 คำไม่ซ้ำ ไม่อ้างว่าเป็นสำรับ 110 ใบหรือคำแปลอย่างเป็นทางการ ทุกใบคละ 5 หมวดต่างกันจาก 10 หมวด ได้แก่ อาหาร สัตว์ สิ่งของ สถานที่/ประเทศ ธรรมชาติ กิจกรรม ผู้คน/อาชีพ ความรู้สึก/ลักษณะ รูปร่าง/เวลา และเรื่องเล่า/วัฒนธรรม มีคลังคำรายใบก่อนเข้าห้อง ภาพกล่องและภาพโต๊ะสร้างใหม่ด้วย image_gen ตาม [manifest](assets.json)

## รอบการเล่น

1. สุ่มคนทายคนแรก หรือหัวห้องเลือกตามที่ตกลงกัน คนทายเลือกเลข 1–5 โดยไม่เห็นคำบนการ์ด
2. คนอื่นได้รับเฉพาะคำที่เลือกบนมือถือ เขียนคำใบ้อย่างอิสระคนละหนึ่งคำ (3 คนเขียนคนละสองคำ) แล้วส่งโดยไม่ปรึกษากัน คำใบ้ที่ส่งแล้วแก้ไม่ได้ในรอบนั้น หากไม่รู้จักคำ ให้ขอเลือกเลขใหม่ได้ก่อนมีใครส่งคำใบ้
3. เพื่อนเห็นคำใบ้ร่วมกันเฉพาะบนมือถือ ระบบตัดคำที่สะกดตรงกันและคำเฉลยตรงตัวอัตโนมัติ ทุกคำในกลุ่มซ้ำถูกตัด รวมคำซ้ำในสองช่องของคนเดียวกัน เพื่อนช่วยตรวจคำคล้าย คำตระกูลเดียวกัน การสะกดผิดและคำผิดกติกาที่ระบบไม่รู้ความหมาย แล้วตัดทุกคำที่เกี่ยวข้อง ทุกคนยืนยันชุดคำใบ้ก่อนเปิดให้คนทาย การเปลี่ยนคำที่ตัดจะล้างการยืนยันเดิมทั้งหมด
4. คนทายและจอกลางเห็นเฉพาะคำใบ้ที่รอด ทายได้ครั้งเดียวหรือเลือกผ่าน ถ้าคำใบ้ถูกตัดหมดให้ข้ามการทายและทิ้งเฉพาะการ์ดปัจจุบัน
5. ทายถูกเก็บการ์ดเป็น 1 คะแนน ทายผิดทิ้งการ์ดปัจจุบันและการ์ดถัดไปอีกใบ ถ้าทายผิดเมื่อเหลือการ์ดสุดท้าย ให้คืนการ์ดที่เคยทายถูกหนึ่งใบถ้ามี ผ่านเสียเฉพาะการ์ดปัจจุบัน จบรอบแล้วเลื่อนคนทายตามลำดับที่นั่ง จบเกมเมื่อสำรับหมด สูงสุด 13 คะแนน

คำใบ้ใช้หนึ่งคำ/หนึ่งแนวคิดตามคู่มือ ตัวเลข ตัวย่อ เสียงเลียนแบบหรือสัญลักษณ์ใช้ได้ ห้ามใช้คำเฉลยที่เปลี่ยนการสะกด คำแปล คำในตระกูลเดียวกับเฉลย คำแต่งขึ้น หรือคำออกเสียงเหมือนเฉลยแต่คนละความหมาย สำหรับภาษาไทยให้คนในวงช่วยพิจารณาคำประสม; เว็บป้องกันข้อความหลายช่องว่าง อักขระซ่อนและข้อความเกิน 40 ตัวอักษร แต่ไม่อ้างว่าตรวจความหมายภาษาได้ครบ

คำตอบออกเสียงเหมือนเฉลยถือว่าถูกตามคู่มือ เว็บจับคู่ตัวพิมพ์และ Unicode แบบ NFKC ก่อน หากข้อความไม่ตรง ให้เพื่อนที่เขียนคำใบ้ทุกคนช่วยยืนยันถูก/ผิดบนมือถือจนเห็นตรงกัน การยืนยันนี้เป็นวิธีเก็บการตัดสินร่วมกันในรูปแบบดิจิทัล ไม่ใช่กติกาคะแนนเพิ่มเติม คนทายและจอกลางไม่มีสิทธิ์เห็นเฉลยหรือส่งคำตัดสินแทนเพื่อน

## ข้อมูลและอำนาจตัดสิน

- Pure engine ไม่ import DOM/network/storage. RNG ถูกส่งจาก server; สุ่มสำรับและคนเริ่มบน server เท่านั้น
- ใช้ระบบบัญชี/Guest/ห้อง/QR/ready/session/reconnect/receipts/transactions เดิม ผู้สร้างเข้าร่วมบนมือถือได้พร้อมเปิดจอกลางแยกได้ Public display ดูอย่างเดียว; owner display ช่วยกดไปรอบถัดไปหลังเฉลยและเริ่มใหม่ผ่านเมนูห้องได้
- ทุก action ตรวจ actor จาก authenticated seat, phase, round, exact shape และ revision ไม่มี client-supplied score, word, random outcome หรือ identity ที่เชื่อถือได้ คำตัดสินร่วมกันเป็นการกระทำของเพื่อนที่ได้รับอนุญาต ไม่ใช่การส่งคะแนนจาก client
- Writing ส่งเฉพาะเฉลยและคำใบ้ที่ตนส่งกลับให้เจ้าของ คำใบ้คนอื่นเปิดให้เพื่อนเมื่อเข้าสู่ review เท่านั้น ผู้ทาย/จอกลางไม่ได้รับเฉลยหรือคำใบ้ที่ถูกตัดก่อนจบรอบ ไม่มี deck order/current card ID/คำอื่นบนใบปัจจุบันใน DTO
- หลังจบรอบเปิดเฉลยและเก็บประวัติเฉพาะคำที่เล่นแล้ว ไม่เปิดการ์ดที่เสียไปเป็นโทษ ระบบไม่บันทึกคำ/credential ลง log
- ใช้ schema 1 และ rulesVersion `repos-base-2018-th-original-v1`. Restore ตรวจสำรับ 13 ใบไม่ซ้ำ การใช้การ์ดและคะแนนย้อนหลัง การหมุนคนทาย รูปแบบคำใบ้/การยืนยัน/คำตัดสินตาม phase. คำใบ้ที่ส่งแล้วและสถานะตรวจคำใบ้กู้ได้หลัง restart. Draft ที่ยังไม่ส่งอยู่เฉพาะหน้านั้น

## การตรวจ

- `tests/just-one.test.ts`: กติกาทุก phase, 3–7 คน, คำซ้ำ/Unicode/คำเฉลย, สิทธิ์, การยืนยันใหม่, คำตอบครั้งเดียว, ความเห็นต่าง, บทลงโทษสุดสำรับ, restore corruption และเล่นจบ 13 คะแนน
- `tests/just-one-integration.test.ts`: HTTP/WS จริง, auth, public/private projections, owner display กับมือถือ, actor impersonation, duplicate receipt, stale revision, restart ระหว่าง review, authenticated resume, full settlement และ rematch
- `tests/browser/just-one.spec.ts`: ผู้สร้างเข้ามือถืออัตโนมัติ จอกลางทั้ง owner/public มือถือ 3 คน ใช้คลังการ์ด ส่งคำใบ้ ตรวจคำซ้ำ ทายถูก/ผิด/คำพ้องเสียง reconnect เล่นจบ และเริ่มใหม่ พร้อมภาพใน ignored `data/qa-just-one/`

การรันกับ Docker local หลัง rebuild: `JO_LIVE=1 GAMEVERSE_E2E_DOCKER=1 npx playwright test --config data/qa-just-one/local.config.ts` (config local อยู่ใน ignored data). ไม่ได้ทดสอบ Safari/อุปกรณ์จริงหรือ Google OAuth provider ในงานนี้ และไม่ได้ deploy

## ชุดคละหมวดและตัวช่วยเปลี่ยนคำ — 1 พฤศจิกายน 2026

ปรับตามคำขอผู้ใช้เป็น100ใบ/500คำไทยไม่ซ้ำ แต่ละใบมี5หมวดต่างกัน และสลับตำแหน่งหมวดระหว่างใบ ไม่แบ่งเป็นใบสัตว์ล้วน/อาหารล้วน ตัวอย่างใบแรกตามที่ผู้ใช้ยกมา: พริกไทย / สามเหลี่ยม / ตุ๊กตา / อิตาลี / ฉาก ชุดนี้แต่งเป็นภาษาไทยสำหรับเว็บ ไม่อ้างว่าเป็นคำแปลสำรับทางการ

แยกตัวเลือกชัดเจน:

- **ขอเลือกเลขใหม่**: ผู้ให้คำใบ้กดได้ก่อนมีใครส่งคำใบ้ ให้คนทายเลือก1–5บนการ์ดเดิม
- **ข้ามคำนี้ · เปลี่ยนการ์ดใหม่**: ตัวช่วยตามคำขอผู้ใช้ ไม่ใช่กติกาให้ผ่านฟรีในเกมกล่อง ใช้โดยคนทายขณะเลือกเลข หรือผู้ให้คำใบ้ในช่วงเขียน/ตรวจคำใบ้ ก่อนเปิดคำใบ้ให้คนทาย สุ่มใบใหม่จาก100ใบที่ยังไม่อยู่ในสำรับ13ใบและไม่เคยเปลี่ยนทิ้ง ไม่เสียคะแนน ไม่ลดจำนวน13ใบ ไม่เปลี่ยนคนทายหรือตาปัจจุบัน ล้างคำใบ้/การตัดคำ/การยืนยัน/ร่างบนมือถือทั้งหมดแล้วกลับให้เลือกเลข ถ้าสำรองหมดจะไม่แสดงปุ่มเปลี่ยน ไม่วนเอาใบเดิมกลับมา
- **ข้ามรอบนี้ · ไม่ทาย (เสียการ์ด1ใบ)**: คนทายใช้ได้เมื่อเห็นคำใบ้แล้ว ตามการผ่านเดิม ทิ้งเฉพาะใบนี้ ไม่หักคะแนนสะสมและเลื่อนคนทายเมื่อจบรอบ

Server RNG เลือกใบแทนและตรวจสิทธิ์/phase/round/exact revision ก่อนเปลี่ยน ห้ามผู้สร้างจอกลางเปลี่ยนแทนผู้เล่น ไม่ส่ง IDใบที่เลือก/ใบสำรอง/ใบที่เปลี่ยนทิ้ง หรือคำเฉลยเก่าให้คนทายและจอกลาง แสดงเพียงจำนวนครั้งที่เปลี่ยน

IDชุดใหม่ใช้ `jo-mix-v1-*` และเก็บ mapping `jo-001`–`jo-060`เดิมไว้อย่างคงที่ใน `legacy-data.ts` เพื่อให้เกมที่บันทึกไว้ยังใช้คำเฉลยและประวัติคะแนนเดิม เกมใหม่/เริ่มใหม่ใช้ชุดคละ100ใบ ห้องเดิมเปลี่ยนใบได้โดยไม่เปลี่ยนความหมายของคำในตาที่ผ่านมา Restore validator รองรับ stateเก่าที่ไม่มี `prompt`/`replaced` และตรวจว่าใบที่เปลี่ยนทิ้งไม่ซ้ำหรือชนกับสำรับปัจจุบัน Draft keyแยก match/round/promptเพื่อไม่ให้คำใบ้เก่ากลับมาหลังเปลี่ยนคำหรือเริ่มใหม่
