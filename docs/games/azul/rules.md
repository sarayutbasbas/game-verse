## แหล่งที่อ่านจริง

- [ผู้จัดพิมพ์ Next Move Games](https://www.nextmove-games.com/en/azul/azul-game/) ยืนยัน 2–4 คน, 30–45 นาที และลิงก์คู่มือ.
- [คู่มือภาษาอังกฤษจากผู้จัดพิมพ์](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Azul-Rules-Next-Move-web.pdf): อ่านครบหน้า 2–6 ของเล่ม และ render หน้า setup ตรวจ mapping ผนังด้วยภาพจริง. ใช้เป็นหลักเหนือบทความสอนเล่น.
- [WikiHow ที่ผู้ใช้ให้](https://www.wikihow.com/Play-Azul): web fetch เปิดไม่ได้ครั้งแรก แต่ดาวน์โหลด HTML ผ่าน curl และอ่าน setup/turn/scoring/endgame ได้ภายหลัง. [ลิงก์แปล](https://www-wikihow-com.translate.goog/Play-Azul?_x_tr_sl=en&_x_tr_tl=th&_x_tr_hl=th&_x_tr_pto=tc) ยังเปิดด้วย web fetch ไม่ได้ จึงใช้ต้นฉบับอังกฤษ. บทความมีคำแนะนำให้โยนแถวเต็มลงพื้นหากช่องสีบนผนังถูกใช้แล้ว; สำหรับผนังสีมาตรฐาน คู่มือทางการห้ามเลือกสีนั้นใน pattern ตั้งแต่แรก จึงใช้ข้อห้ามตามคู่มือ และไม่ยกข้อยกเว้น gray-wall มาปน.

## กติกาที่ใช้

- 100 ชิ้น สีละ 20: น้ำเงิน/เหลือง/แดง/ดำ/ขาว. 2/3/4 คนใช้โรงงาน 5/7/9 วง เติมวงละ 4 จากถุง. เริ่มคะแนน 0. ผนังมาตรฐานแถวแรก B Y R K W แถวถัดไปหมุนขวาทีละช่อง; mapping กลางอยู่ `src/games/azul/types.ts` ทั้ง engine/UI ใช้ชุดเดียวกัน.
- ผลัดตาตามลำดับที่นั่ง. หยิบสีเดียวทั้งหมดจากโรงงานหนึ่งวงหรือกลางโต๊ะ; สีอื่นในโรงงานนั้นไปกลาง สีอื่นในกลางยังอยู่. คนแรกที่หยิบจากกลางรับ marker ใส่ช่องว่างแรกของพื้นก่อนกระเบื้องส่วนเกิน. หยิบ marker เดี่ยวไม่ได้.
- วางแถวเตรียมเดียว ความจุ 1–5 จากขวาไปซ้าย สีเดียวกับที่มีอยู่ และสีนี้ต้องยังไม่มีบนผนังแถวนั้น. UI ไม่เสนอแถวที่เต็มเป็นปลายทางเพราะไม่มีช่องรับ; เลือกพื้นโดยตรงได้. เศษไปพื้น 7 ช่อง ส่วนเกินกว่านั้นไปกองทิ้งทันที. ไม่แบ่งระหว่างหลายแถว.
- โรงงานและกลางไม่มีสีกระเบื้องเหลือ → server ปูผนังและคิดผลอัตโนมัติครั้งเดียว. ทุกคนทำแถวเต็มจากบนลงล่าง ย้าย 1 ชิ้นตรงสีบนผนัง ที่เหลือจากแถวนั้นทิ้ง; แถวไม่เต็มคงไว้.
- วางแล้วช่องเดี่ยวได้ 1; ถ้าต่อกลุ่มแนวนอนหรือแนวตั้งได้ความยาวกลุ่มที่ติดกัน รวมชิ้นใหม่. ต่อทั้งสองแนวคิดผลรวมทั้งสองกลุ่ม ชิ้นใหม่ถูกนับสองครั้ง. ไม่ต่อข้ามช่องว่าง/ทแยง.
- หักพื้นตามช่อง 1,1,2,2,2,3,3 รวมไม่เกิน 14 และคะแนนไม่ต่ำกว่า 0 หลังคิดทั้งรอบ. marker นับค่าปรับตามช่องที่อยู่ แต่ไม่ทิ้งเข้าถุง. กระเบื้องพื้นกลับกองทิ้ง.
- ตรวจจบหลังทุกคนคิดผลครบ: มีผนังแนวนอนครบ 5 ช่องอย่างน้อยหนึ่งคน. โบนัสแถวครบ +2, คอลัมน์ครบ +7, สีครบทั้งห้าตำแหน่ง +10. คะแนนสูงสุดชนะ เสมอใช้จำนวนแถวครบ ถ้ายังเสมอชนะร่วม.
- ถ้ายังไม่จบ ผู้รับ marker เริ่มรอบใหม่. เติมถุงจากกองทิ้งและสุ่มเมื่อถุงหมดระหว่างเติมโรงงาน ใช้ของในถุงเดิมก่อน. หากทั้งสองแหล่งไม่พอให้บางวงมีน้อยกว่า 4. ไม่สุ่มใหม่ตอน refresh/reconnect.

## ขั้นตอนเว็บและข้อวินิจฉัยที่ผู้ใช้ยืนยัน

- คู่มือเลือกคนไปโปรตุเกสล่าสุดเป็นผู้เริ่ม. เว็บให้ owner เลือกผู้เล่นหรือสุ่มที่ server แทนการตรวจเกณฑ์ทางกายภาพ. ที่นั่งเรียงตามการเข้าห้องแทนตำแหน่งรอบโต๊ะ.
- **Floor เต็มก่อนรับ marker:** คู่มือหลักไม่ได้ระบุกรณีนี้ตรง ๆ. ผู้ใช้ยืนยัน 2026-10-14 ให้ถือ marker ข้างกระดานเพื่อระบุผู้เริ่มรอบหน้า ไม่เพิ่มค่าปรับเกิน 7 ช่อง ไม่ปะปนกับกองทิ้ง. นี่เป็นข้อวินิจฉัยเว็บที่ยืนยัน ไม่อ้างว่าเป็นข้อความ FAQ ทางการ.
- ถ้าไม่มีใครหยิบกลางเพราะโรงงานสีเดียวทั้งหมด marker ไม่ถูกย้ายให้คนใหม่; คงผู้เริ่มคนเดิมตามการถือ marker.
- Lobby ทุกคนกดพร้อมและออนไลน์ก่อน owner เริ่ม; จอกลางไม่กินที่นั่ง. มี rematch หลังจบโดยใช้ห้อง/ที่นั่ง/session เดิม.
- `playing` คือ drafting; wall settlement เกิด atomic ใน accepted draft สุดท้าย → `results` หรือ `finished`. ไม่รอ browser/timer/จอกลางเพื่อคิดคะแนน.
- ช่วง `results` พักดูผล: **ผู้เล่นที่เชื่อมต่อคนใด หรือ owner ผ่านจอกลาง/มือถือกดเริ่มรอบถัดไปได้** จึงไม่ค้างเพราะคนหนึ่งหลุด. ไม่มีการกดพร้อมทุกคนในช่วงนี้. ช่วง drafting ยังรอเจ้าของตากลับเข้าที่นั่งตามนโยบายเดิม ไม่ข้าม/เล่นแทนเอง.
- หากเติมแล้วโรงงานว่างทั้งหมดจริง ๆ เงื่อนไขจบ drafting ใช้ทันทีและเข้าสู่ผลรอบ ไม่สร้างกระเบื้องเพิ่ม ไม่กำหนดผู้ชนะนอกเงื่อนไข และไม่ค้างอยู่ในตาที่ไม่มี legal draft.
- กระดานทั้งหมดเปิดเผยต่อทุกคน. `me` มี legal offers/targets/preview จาก server สำหรับตัวเอง; ลำดับถุงและ RNG เป็น server-only.

ไม่มีข้อกติกาค้างการยืนยัน ณบันทึกนี้. งานภาพเป็น CSS shapes/ตัวอักษรและปก SVG ชั่วคราวตามขอบเขต ไม่ใช่ artwork รุ่นสมบูรณ์.
