## เตรียมสวน

แต่ละสีมีนก 28 ตัว สีผู้เล่นตามที่นั่ง แดง ฟ้า เหลือง เขียว ดำ เล่น 2 คนเพิ่มฝูงกลางสีเหลืองที่ไม่คิดคะแนน คนให้อาหารนกล่าสุดเริ่มก่อน เลือกผู้เริ่มจากห้องรอได้

2–3 คนจัดคอลัมน์ [สนหอม, แอชใหญ่, บ้านสุนัข] / [บ้านชนบท, รังแขวน] / [นกตื่นเช้า, เอล์มเดียวดาย, รังเหยี่ยว] ความยาว 3–2–3
4 คนเพิ่มคอลัมน์ [ไร่ข้าวโพด, โอ๊กยักษ์] ทางซ้าย เป็น 2–3–2–3
5 คนเพิ่ม [เบิร์ชผลัดเปลือก, อ่างนกสุขใจ, โพรงจิ้งจอก] อีกคอลัมน์ทางซ้าย เป็น 3–2–3–2–3

คอลัมน์ที่มี 2 ช่องเยื้องครึ่งช่อง ไม่มีแถวตรงทั่วกระดาน ติดกันได้แนวตั้งภายในคอลัมน์ และสองช่องที่สัมผัสขอบในคอลัมน์ข้างเคียง ไม่วนข้ามขอบกระดาน รังเริ่มต้น: สน/แอช/เอล์ม/เบิร์ชอย่างละ 1 โอ๊ก 2; แผ่นอื่นไม่มีรังที่ใช้วาง

## หนึ่งรอบ

1. อพยพ: ใส่นกสีตนจากแหล่งพักคนละ 2 ตัวลงถุง ผู้ครองนกตื่นเช้าเพิ่มอีก 1 ตัว ฝูงกลางใส่ 4 ตัวรอบแรก 2 ตัวในรอบ 2–5 ถ้าสำรองไม่พอใส่ได้เท่าที่มี
2. รับนก: คนละ 2 ตัวสีตนกับสุ่ม 2 ตัวจากถุง มือลับ 4 ตัว ผู้ครองอ่างนกสุขใจรับก่อน สุ่มจากถุง 3 เลือกคืน 1 จากสามตัวที่สุ่ม ก่อนคนอื่นรับตามลำดับ
3. ผลัดกันวางจากมือ 1 ตัวต่อหนึ่งตา ลงพื้นที่ใดก็ได้ รวมสีคู่แข่ง นกสีเดียวในพื้นที่เดียวต้องรวมเป็นฝูงเดียว ไม่มีจำกัดความสูง วางลงรังว่างหรือรังสีเดียวกันได้ รวมฝูงบนพื้นเข้ารังเมื่อเลือกวางในรัง รังนับ +1 หากมีนก บ้านนกนับ +1 ตาตนใช้โบนัสได้ 1 อย่าง ก่อนหรือหลังการวาง จบตาหลังวางแล้วหรือหลังใช้โบนัสทั้งสองอย่าง
4. นกทุกมือหมดจึงดูแลสวน: คิดคะแนนทุกพื้นที่ก่อน เรียงคอลัมน์ซ้ายไปขวา บนลงล่าง จัดลำดับเล่นใหม่คะแนนมากก่อน เสมอผู้ถึงคะแนนนั้นก่อนอยู่ก่อน จากนั้นเปิดผลช่วงดูแลตามลำดับแผ่นเดิมและกำหนดผู้ควบคุมสัตว์ แล้วเปลี่ยนรอบ
5. ต้นรอบ 4 ได้บ้านนกคนละ 1 หลัง ต้นรอบ 5 ได้สายฟ้าคนละ 1 อัน

## คะแนนและผลพื้นที่

| พื้นที่ | ที่ 1 / 2 / 3 | ผล |
| --- | --- | --- |
| สนหอม | 3 / 5 / 2 | รัง 1 |
| แอชใหญ่ | 5 / 3 / 2 | รัง 1 |
| บ้านสุนัข | 1 / 3 / 1 | ผู้ครองควบคุมสุนัข |
| บ้านชนบท | 0 / 1 / 1 | ผู้ครองควบคุมแมว |
| รังแขวนโงนเงน | 5 / 3 / 1 | หากมีนกรวมตั้งแต่ 4 ส่งนกทั้งหมดที่ย้ายได้ไปลานหลังคิดคะแนน |
| นกตื่นเช้า | 3 / 4 / 5 | ผู้ครองเพิ่มนกลงถุง 1 ตอนอพยพ |
| เอล์มเดียวดาย | 5 / 0 / 2 | รัง 1 |
| รังเหยี่ยว | 1 / 1 / 2 | ผู้ครองควบคุมเหยี่ยว |
| ไร่ข้าวโพด | 0 / 2 / 2 | ผู้ครองควบคุมหุ่นไล่กา |
| โอ๊กยักษ์ | 6 / 4 / 3 | รัง 2 |
| เบิร์ชผลัดเปลือก | 5 / 3 / 3 | รัง 1 |
| อ่างนกสุขใจ | 2 / 0 / 1 | ผู้ครองสุ่ม 3 คืน 1 ตอนรับนก โดยรับก่อนคนอื่น |
| โพรงจิ้งจอก | 0 / 0 / 1 | ผู้ครองควบคุมจิ้งจอก |

นับรังและบ้านนกเป็นนกเพิ่มทุกกรณี ฝูงที่เสมอไม่ได้คะแนนและกินอันดับทั้งหมดที่ครอง เช่น 5/2/2/1 ตัว: ฝูง 5 ได้อันดับหนึ่ง ฝูง 2 ยกเลิกอันดับสองกับสาม ฝูง 1 คืออันดับสี่ ไม่มีคะแนน เมื่อเสมออันดับหนึ่งไม่มีผู้ควบคุมแผ่น สัตว์ไม่มีผู้ควบคุมในรอบนั้น แม้ผู้ควบคุมเดิมยังมีนกอยู่ สัตว์ยืนที่เดิมจนถูกใช้ ผู้ควบคุมตัดสินจากแผ่นบ้านเท่านั้น

## โบนัส

- บ้านนก: รอบ 4–5 วางบนฝูงใดก็ได้ที่มีนก รวมของคู่แข่ง ใช้ทรัพยากรของผู้วาง แต่เพิ่มจำนวนให้สีของฝูงนั้น +1 ฝูงที่ปกป้องเพิ่มนกไม่ได้และนำออกไม่ได้ ทั้งสัตว์/สายฟ้าและการย้ายอื่น
- สายฟ้า: รอบ 5 ส่งนกจากพื้นที่ไปน้ำพุ หรือเอารังว่างออกจากเกม ห้ามโจมตีฝูงที่มีบ้านนก ห้ามใช้กับนกในน้ำพุ
- สัตว์: ใช้ได้เมื่อควบคุมจากช่วงดูแลรอบก่อน ตัวละ 1 ครั้งต่อรอบ และนับเป็นโบนัสหนึ่งครั้งของตานี้ ขั้นที่ 1 ต้องย้ายตามข้อกำหนด ขั้นที่ 2 เลือกใช้หรือข้ามได้
  - สุนัขย้ายไปช่องติดกัน แล้วอาจไล่นกหนึ่งตัวไปช่องติดกันในทิศใดก็ได้ ถ้าทิศนั้นออกนอกกระดาน ส่งไปน้ำพุ
  - แมวย้ายไปช่องติดกันที่มีนกรวมมากที่สุด เสมอเลือกได้ แล้วอาจส่งนกหนึ่งตัวไปน้ำพุและย้ายนกอีกหนึ่งตัวจากที่แมวหยุดไปช่องติดกัน ทำส่วนย้ายต่อหากมีเป้าหมายที่ทำได้
  - เหยี่ยวย้ายไปพื้นที่อื่นใดก็ได้ แล้วอาจส่งนกหนึ่งตัวจากพื้นที่ที่หยุดไปน้ำพุ
  - จิ้งจอกย้ายสองพื้นที่พอดี ไม่ย้อนกลับไปจุดเดิม แล้วอาจส่งนกหนึ่งตัวจากแต่ละพื้นที่ที่ผ่าน/หยุดไปน้ำพุ หากใช้ผลต้องเลือกจากทุกพื้นที่ในเส้นทางที่มีนกซึ่งย้ายได้
  - หุ่นไล่กา: เมื่อได้ควบคุมครั้งแรกหรือเปลี่ยนผู้ควบคุม เลือกจุดบรรจบสามพื้นที่ หากคนเดิมควบคุมยังยืนที่เดิม ตอนใช้ไม่ย้าย ส่งนกจากสองพื้นที่ต่างกันที่ติดหุ่นอย่างละหนึ่งตัวไปน้ำพุ

เมื่อสัตว์ย้ายนกไปพื้นที่มีรังว่าง เจ้าของสีเป็นผู้เลือกรังหรือพื้นตาม FAQ ล่าสุด ส่วนฝูงกลางให้ผู้ก่อผลเป็นผู้เลือก

## น้ำพุและฝูงกลาง

ผู้เป็นเจ้าของสีที่ได้รับผลเลือกช่องน้ำพุ ไม่ใช่ผู้โจมตี ต้องมีนกอยู่ครบทุกช่องที่เชื่อมเส้นรองรับด้านล่างก่อน วางแล้วไม่ย้าย ถ้าเต็มส่งไปลานแทน
- 2–3 คน: 12 ช่อง จำนวนจากล่างขึ้นบน 4/3/2/2/1 คะแนน 1/2/3/4/6 ชั้น 2 ช่องที่ซ้ำกันมีเส้นตั้งและเส้นไขว้ ดังนั้นแต่ละช่องบนต้องมี 2 ช่องล่างครบ
- 4–5 คน: 18 ช่อง จำนวน 4/4/4/3/2/1 คะแนน 1/1/2/3/5/8 ชั้น 4 ช่องที่อยู่ซ้ำตำแหน่งรองรับแนวตั้งตำแหน่งเดียว ส่วนสามชั้นบนรองรับสองช่องด้านล่าง
- ลานนับตัวละ 1 เมื่อจบเกมเท่านั้น

ฝูงกลางแย่งอันดับและทำเสมอได้ แต่ไม่รับคะแนน ไม่รับสิทธิ์สัตว์ และไม่ใช้ผลเพิ่ม/เปลี่ยนมือ หากผลแผ่นสถานที่ส่งนกกลางไปน้ำพุหรือลาน ให้กลับแหล่งพักแทน เมื่อถูกสัตว์หรือสายฟ้าส่งไปน้ำพุ ผู้ก่อผลเลือกช่องแทนฝูงกลาง

## จบเกม

ดูแลรอบ 5 ตามปกติก่อน ส่งนกที่เหลือในถุงไปลาน คะแนนเพิ่ม: ฝูงที่ใหญ่ที่สุดในพื้นที่เดียว 10 (มีผู้ชนะเดี่ยวเท่านั้น รวมฝูงกลางในการเปรียบเทียบ), สัตว์ที่ควบคุมตัวละ 3, น้ำพุตามระดับทุกตัว, ลานตัวละ 1 ผู้คะแนนมากที่สุดชนะ เสมอเทียบขนาดฝูงใหญ่ที่สุดในหนึ่งพื้นที่ แล้วนกในน้ำพุ แล้วชนะร่วมกัน

## ออนไลน์

เซิร์ฟเวอร์สุ่มถุง แจกมือ คุมลำดับ คิวผล และคะแนนทั้งหมด จอกลางแสดงนกที่วางแล้วทุกสีและคะแนนทุกคน แต่ไม่มีมือ ลำดับถุง หรือคิวรับนกที่ยังไม่เปิด มือถือได้รับเฉพาะมือ ฝูง คะแนน และสำรองของเจ้าของ ฝูงผู้อื่นในน้ำพุมีเพียงสถานะช่องถูกใช้แล้ว รายชื่อ/สีผู้เล่น และเป้าหมายโบนัสที่ถูกต้องอ้างอิงข้อมูลสาธารณะบนจอกลาง

คำสั่งทุกตัวตรวจรูปแบบ ตา และทรัพยากรบน server รับเพียง player session ที่รับรองแล้ว จอกลางสาธารณะและผู้จัดการไม่สามารถวางแทนใคร คิวเลือกน้ำพุ/รัง/หุ่นไล่กา/คืนนกคงอยู่เมื่อหลุดหรือ restart process ไม่มี timeout เลือกแทนผู้เล่น ใช้ receipts/revision และ durable store เดิม เริ่มใหม่โดยผู้จัดการผ่านเมนูเดิม
