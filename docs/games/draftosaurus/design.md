# Draftosaurus visual direction

A miniature dinosaur zoo as the centerpiece: raised timber rails, soft sculpted creatures, a bright river. Forest #183f37, fern #82be96, sun gold #f3cd6d, lagoon #4aaeb7, parchment #fff7dc. Use the existing Thai font and a compact heavy title. Center the board itself; left-align actionable Thai copy. Shared display shows a balanced park grid, phones one large personal park and a private hand beneath. Quiet circular toolbar controls, gold roll/confirm actions. Avoid decorative frames around each enclosure: the generated timber boundaries already carry that meaning.

Generated eight independent assets with built-in image_gen: a new box, overhead six-pen Summer board and six transparent two-frame dinosaur strips. Exact prompts and source/export paths in assets.json; workspace masters in assets/source/draftosaurus; runtime exports in public/art/draftosaurus. Export script scripts/export-draftosaurus.mjs. Each sprite strip is 512×256; one-cell stills are 256×256 for learning illustrations. Generated scene stays independent of rules; code owns every label, score, click target and region.

Board has a shallow perspective and a flowing river highlight. Dinosaurs use actual two-pose sprite frames, and new placements settle into the pen. Six-sided CSS die rotates for 1100ms on a newly accepted roll, then shows the authoritative face; reconnect/snapshot does not replay it. All motion can be turned off locally and honors prefers-reduced-motion. Touch targets and focus rings remain visible; species have different silhouettes plus Thai names, and die constraints also use text.
