# Mansions of Madness — ชุดด่านแฟนเมดที่ใช้กลไก Second Edition

ผู้ใช้เลือก **Second Edition + Beyond the Threshold** และยืนยันให้สร้าง **ด่านแฟนเมดตามกติกาทางการ** เมื่อทราบว่าคู่มือสาธารณะไม่ได้ให้ข้อมูลสถานการณ์ลับในแอปครบ งานนี้จึงไม่อ้างว่าเป็นแอปทางการ ไม่ใช้ชื่อด่านทางการ และไม่อ้างว่ามีการ์ด/ตัวละครจากกล่องจริงครบชุด

## ชุดเนื้อหาที่เล่นได้

1. **เสียงฝีเท้าในบ้านฝน** — ด่านเริ่มต้น ค้นเอกสารสามชิ้น ไขตู้รหัส ปิดรอยแยก และกลับทางเข้า มีเวลา 14 รอบ
2. **แขกคนสุดท้ายก่อนเที่ยงคืน** — งานเลี้ยงลวงตา ใช้ Influence สนทนาและสืบหาบันทึก มีเวลา 15 รอบ เป็นเรื่องใหม่ ไม่ใช่ Vengeful Impulses
3. **ประตูที่จดจำคุณ** — ต้องเปิดกลไก Beyond the Threshold ใช้สิ่งของติด Key/Evidence และสลับห้องที่ค้นพบในรอบ 3/6/9 มีเวลา 16 รอบ เป็นเรื่องใหม่ ไม่ใช่ Gates of Silverwood Manor

ทุกด่านใช้ 9 ห้องสร้างใหม่ สุ่มตำแหน่งห้องนอกเหนือจากโถงเริ่มต้น ทุกห้องเป็นหนึ่ง space เพื่อให้แตะเล่นบนมือถือได้ กำหนดขอบห้องเป็นประตู ยกเว้นช่องเปิดของโถง/ลานกลางบ้าน การเดินนับผ่านประตูที่เปิดสำรวจแล้วได้ แต่การวัด range ไม่นับผ่านประตู ห้องยังไม่พบไม่ได้รับชื่อ ภาพ ตำแหน่งอัตลักษณ์หรือข้อมูลโหนดใน projection

นักสืบสร้างใหม่ 6 คน: เอเลนา โนอาห์ มาเรีย โจนัส อาร์เธอร์ และไอริส (เพิ่มเมื่อเปิดโหมดเสริม) มี 6 ทักษะ รวมค่าพลัง 21, Health+Sanity=14. ไม่ใช้ชื่อ/ค่าตัวละครทางการที่ยังไม่มีการ์ดต้นฉบับให้ตรวจ ผู้เล่น 1–5 คน; Solo ควบคุมนักสืบสองคน คนอื่นคนละหนึ่งตัว เลือกไม่ซ้ำกันและกดพร้อมบนมือถือก่อนเข้าฉาก

สิ่งของแฟนเมด 6 แบบ และกอง Damage/Horror แฟนเมดอย่างละ 40 ใบ บางใบ Resolve Immediately แล้วคว่ำ บางใบ Keep Faceup ลดทักษะ; ชื่อ/ผลจริงอ่านได้ในคลัง ไม่ใช่การถอดเด็คทางการ 80 ใบ เริ่มพร้อมชุดอุปกรณ์แนะนำตามโปรไฟล์ และแลกกันได้ฟรีระหว่างเตรียมตัวก่อนทุกคนพร้อม

## กติกาโครงสร้างที่นำมาใช้

- ช่วงนักสืบเลือกใครเริ่มก่อนก็ได้ แต่ต้องทำตาของคนหนึ่งให้เสร็จก่อนคนถัดไป นักสืบทำได้ไม่เกิน 2 แอ็กชันและจบตาโดยไม่ใช้ครบได้
- Move ใช้ 1 แอ็กชัน ได้ 2 ก้าว เดินทีละช่องที่ติดกัน แทรกแอ็กชันอื่นระหว่างก้าวได้ และใช้ Move ซ้ำเพื่อเพิ่มก้าวได้ นักสืบบาดเจ็บหนักใช้ Move ได้ครั้งเดียวต่อตา
- Search/Explore/Interact/Attack/Trade และแอ็กชันสิ่งของใช้ 1 แอ็กชันตามไอคอนของเอฟเฟกต์ Explore ในชุดด่านนี้ระบุว่าเผยห้องโดยไม่เคลื่อนตัวเพิ่มเติม
- Trade ทำการให้/วาง/หยิบได้หลายชิ้นในแอ็กชันเดียว เฉพาะของตนและกองในช่องเดียวกัน การให้เพื่อนในช่องเดียวกันเป็นการแลกที่ผู้เล่นตกลงกันเอง ไม่มีการหยิบของคนอื่นโดยพลการ Clue ไม่ใช่ possession และแลกไม่ได้
- ใช้เต๋าแปดหน้า: success 3 หน้า, investigation 2 หน้า, blank 3 หน้า จำนวนเต๋าตามค่าทักษะหลังหักผลการ์ดหงาย ใช้ Clue แปลง investigation เป็น success ได้ชิ้นต่อผล ไม่มีการเลือกผลเต๋าจาก client
- Darkness ห้ามใช้ Clue ทั้งแปลงเต๋าและเพิ่มขั้นปริศนา ถ้าไม่มี Light Source ในช่องนั้นหรือช่องติดกัน ภาพ/ข้อมูลห้องระบุความมืดเสมอ
- Attack ประชิด/มือเปล่าเฉพาะช่องเดียวกัน ระยะไกลไม่เกิน 3 ช่องและไม่วัดผ่านประตู/กำแพง สคริปต์โจมตีของชุดแฟนเมดกำหนดว่า damage = จำนวน success + โบนัสอาวุธที่เขียนไว้บนการ์ด
- ก่อนทำแอ็กชันอื่นนอกจาก Move/Attack ในช่องมอนสเตอร์ หรือออกจากช่องมอนสเตอร์โดยสมัครใจ ต้อง Evade มอนสเตอร์ awareness สูงสุด สคริปต์แฟนเมดใช้ Agility เทียบ awareness; พลาดรับ damage 1 และเสียแอ็กชันนั้น หรือเสียก้าวเดินที่เหลือถ้ากำลังออกจากช่อง
- Code puzzle สามตำแหน่ง เลข 1–4 อนุญาตเลขซ้ำ ให้ขั้นตาม Lore หนึ่งคำตอบใช้หนึ่งขั้น เพิ่มขั้นด้วย Clue ได้ ข้อมูลตอบกลับใช้ multiset เพื่อไม่นับเลขซ้ำเกินจริง ปิดปริศนาได้ ประวัติยังอยู่สำหรับการลองครั้งต่อไป
- Damage/Horror รับแบบหงายแล้วทำตาม trait; ใบที่คว่ำไม่เปิดชื่อหรือรหัสให้แม้แต่เจ้าของ การคืนใบคว่ำสุ่มแล้วสับกลับกอง
- แตะ Health ครั้งแรกเป็น Wounded และคืนความเสียหายคว่ำทั้งหมด ถ้าบาดเจ็บหนักแล้วแตะ Health อีกครั้งถูกกำจัด Sanity ใช้ลำดับเดียวกัน แต่ครั้งแรกได้ Insane/เป้าหมายลับแฟนเมดและคืน Horror คว่ำ เป้าหมายมีเงื่อนไขตามการ์ด ไม่ใช่เพียงการซ่อนด้วย CSS
- ถูกกำจัดแล้ววาง possession ทั้งหมดไว้ในช่องเดิม ไม่เล่นตาต่อ ที่เหลือมีโอกาสถึงจบช่วงนักสืบรอบถัดไป ถ้าถูกกำจัดทั้งหมดแพ้ทันที ด่านอาจแพ้เพราะครบกำหนดเวลาก่อนหน้านั้น
- หลังทุกคนจบตา ช่วง Mythos ทำ Event → Monster activation → Horror checks. Horror check เลือกมอนสเตอร์ใน range ที่ horror สูงสุดคนละหนึ่งตัว สคริปต์แฟนเมดกำหนดทักษะและผลลัพธ์ที่แสดงในกล่องทดสอบ

### Beyond the Threshold

นำ **กลไกกุญแจและการย้ายแผ่นห้อง** มาใช้ในด่านเสริม สิ่งของติด Key ได้ Key/Evidence traits และทิ้งออกจากเกมไม่ได้ แต่ส่งให้เพื่อนหรือวางในห้องได้ โทเคนอยู่กับชิ้นเดิมตลอด ผู้ถือสิ่งของนี้ต้องเป็นผู้ทำพิธีในด่านเสริม

ย้ายเฉพาะห้องที่ถูกเผยบนกระดานแล้วและไม่ย้ายโถงเริ่มต้น โดยสลับพิกัดของแผ่นห้อง ทุกตัวนักสืบ มอนสเตอร์ โหนด ความมืด การ์ดบนพื้นและประวัติปริศนายังอยู่กับ room ID เดิม จึงเคลื่อนตามแผ่นห้องไปพร้อมกัน

**ไม่ได้เพิ่ม Beyond the Threshold แบบครบกล่อง**: ไม่ได้ถอด Akachi/Wilson, การ์ดทางการทั้งหมด หรือสคริปต์สองด่านในแอปมาใส่ นอกจากนี้ด่านชุดนี้ไม่ใช้ Fire, Barricade, Secret Passage, Spell, Push, Set Fire และ Steal จึงไม่แสดงปุ่มที่ไม่รองรับ ไม่ควรใช้ engine นี้เปิดด่านทางการที่ต้องใช้เนื้อหาเหล่านั้นโดยไม่เพิ่มกติกา/แหล่งข้อมูลก่อน

## อำนาจตัดสิน ข้อมูล และการกู้คืน

Pure engine/สถานการณ์อยู่ฝั่ง server. `catalog.ts` มีเฉพาะข้อมูลโปรไฟล์/การ์ดและชื่อด่านที่อ่านได้ก่อนเล่น ส่วน `scenarios.ts` มีตำแหน่ง โหนดรางวัล และคำตอบรหัส ห้าม import เข้าฝั่ง client

ใช้ account/Guest/QR/ready/session/receipts/revision/SQLite/Postgres เดิม การสร้างห้องพาผู้สร้างเข้ามือถืออัตโนมัติ เปิด owner display แยกได้ Public display ดูอย่างเดียว ยกเว้น owner display สามารถดำเนินช่วง Mythos ซึ่งไม่ใช่การตัดสินใจลับและเริ่มใหม่ผ่านเมนูห้องได้

ทุกคำสั่งตรวจ exact payload, authenticated owner ของ hero, phase, action/movement budget, ระยะ, สินทรัพย์, แสง, ขั้นปริศนา และ actor ของ pending test ก่อน commit. Invalid action ไม่เปลี่ยน state; คำสั่งซ้ำใช้ receipt เดิม; stale revision ต้องปรับตาม snapshot ปัจจุบัน ไม่เอาคำสั่งเก่าไปเล่นในตาใหม่

Public DTO ส่งเฉพาะห้องที่พบแล้ว มอนสเตอร์ที่เผยแล้ว จำนวนอาการ/ข้อความการ์ดหงาย possession ที่หงาย และผลทดสอบที่เปิดแล้ว Private DTO เพิ่มเฉพาะนักสืบของบัญชีนั้น สถานะเป้าหมายเสียสติและตัวเลือกที่ server อนุญาต ไม่ส่งเด็ค ความเรียงเด็ค คำตอบรหัส หรือหน้าการ์ดคว่ำ

Restore schema 1 ตรวจห้อง/พิกัด/อัตลักษณ์ไม่ซ้ำ 40+40 การ์ดครบ กอง/เจ้าของ/faceup ถูกต้อง สิ่งของ/Key เหตุการณ์/หลักฐาน และ pending test/puzzle/phase. การกู้คืนยึด session token เดิม ไม่ใช้ display name; pending dice และประวัติปริศนาคงเดิมหลัง restart
