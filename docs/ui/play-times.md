# Approximate game play times

Checked 2026-11-02. These are advertised box-game estimates, not measured browser sessions or enforced timers. Publisher/distributor product pages and printed box information take precedence over rounded existing catalogue values. The Name It source is the Japanese exhibitor listing for the matching 69-card dog edition. Perch uses the publisher’s play-time icon image on its product page (45–60 minutes). Bomb Busters uses Pegasus’s 20–40 minute range rather than rounding it to 30.

The gallery (including recent games) and each pregame detail page share src/shared/play-times.ts. Details link to each source and qualify game modes, fan scenarios, adapted decks and per-mission/session scope. Love Letter shows a combined 15–20 minute envelope with Classic 20 and Marvel about 15 separately; Asmodee labels Marvel “15 Minutes or less.” Critter Kitchen’s 55–70 estimate covers the publisher’s 1–5-player base game; expanded player counts can take longer. Catalogue durationMinutes retains the upper range endpoint for compatibility.
